## 共同规则

- 趋势窗口为 `TREND_WINDOWS = (20, 60, 120)`。
- 除股指收盘位置多头和股指收盘位置熊市空头外，冻结策略的多头还要求**滞后一交易日**的年化展期收益严格大于 0；目标权重 +1。
- 冻结策略的空头只在市场趋势小于 0 时启用。带展期过滤的策略还要求品种趋势小于 0、滞后一日展期收益小于 0，且空头覆盖多头。股指收盘位置多头没有空头。股指收盘位置熊市空头不看展期，也不看单品种趋势：收盘位置低于 0.4 做多，熊市里其余日子三个品种一起做空，再按过去 20 日波动把整本仓位缩小到不超过 1 倍。
- 按池宽分配 1 倍名义敞口，下一交易日第一根可交易开盘执行；目标权重不变则不调整仓位。
- 峰值回撤达到 10% 时清仓并停 10 个交易日。
- 商品研究期 2011–2021；股指 IF/IH/IC 研究期从共同上市日 2015-04-16 到 2021。首个有效信号可能因数据覆盖和趋势预热而更晚。

原商品收盘位置策略 `commodity_close_location_reversal` 不对多头应用 carry 过滤，仍是探索规则，不在冻结注册表中。`index_close_location/` 现在只放股指等权收盘位置这一个信号函数，供熊市空头和股指研究共用，本身不是策略。

股指熊市空头 `index_close_location_bear_short`（2026-10-28 冻结）在 `index_bear_reversal/`。阈值 0.4。收盘位置低于 0.4 次日做多，熊市里也做多；20/60/120 日趋势为熊且收盘位置不低于 0.4 时，三个品种次日做空。仓位按过去 20 日等权波动缩小，不超过 1 倍。下单按当天的中金所非套保开仓限额成交。研究期年化 13.0%、Sharpe 1.26、最大回撤 −11.1%。2022 是 +16.8%、Sharpe 1.11、最大回撤 −12.1%。说明见 [`docs/index_guide.md`](../docs/index_guide.md)。

## 本次研究结果

三条冻结策略的正式账本由 `backtest.engine` 运行。商品两条由 `python -m research.report.strategy_report` 按冻结规则重算并逐日核对，画净值回撤、对比买入持有、只保留某一部分时的净值三类图，结果在 `runs/reports/commodity/`。股指熊市空头的净值回撤和对比买入持有图由 `backtest.engine --market index --research` 直接写在账本的 `plots/` 下。

- 商品原策略：2011-01-14 至 2021-12-30，年化 5.6%、Sharpe 1.03、最大回撤 −6.5%。
- 商品收盘位置策略：同期，年化 6.2%、Sharpe 1.12、最大回撤 −6.0%。
- 股指熊市空头：2015-04-16 至 2021-12-30，年化 13.0%、年化波动 10.1%、Sharpe 1.26、最大回撤 −11.1%、Calmar 1.17；2022 年 +16.8%、Sharpe 1.11、最大回撤 −12.1%。
- 以上均为 1 亿元、历史手续费加每边 1 跳（股指 2015 年 0.2 点）。股指熊市空头另外按当天的中金所开仓限额成交。组成部分账本不能相加。

商品策略和研究记录见 [`docs/guide.md`](../docs/guide.md)，股指策略见 [`docs/index_guide.md`](../docs/index_guide.md)。常用命令：

```bash
python -m backtest.engine --research
python -m backtest.engine --market index --research
python -m research.report.strategy_report
```

不要因策略已冻结就自行启动 OOS；只有用户明确指定窗口后才能运行，并须遵守 [`AGENTS.md`](../AGENTS.md) 中的数据分区与台账规则。
