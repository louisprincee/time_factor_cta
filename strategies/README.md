# 策略

当前唯一保留的商品策略是 `ts_low` 纯多头，配置见 [`ts_low.json`](ts_low.json)。
因子为 `ts_low - ts_high`；收盘产生信号，下一可交易日开盘入场，严格高于该品种
自身过去窗口的分位阈值才做多，不做空、不反向。

研究参数网格为回看 60/250/750 个有效交易日、持有 1/5/20 个有效交易日、
阈值前 10%/15%/20%。整数手数组合回测固定使用 250 日、前 20%、持有 5 日；
固定回测不是对这 27 组逐一运行。

从仓库根目录运行：

```bash
python -m backtest.engine --research
python -m backtest.engine --validation
```

入口说明、账本假设、成本模型、输出表和净值/回撤图路径见根目录
[`README.md`](../README.md) 的“策略回测”章节。`--oos` 会读取 2023–2025，
必须在明确批准后才运行；该样本已在此前研究中被读取，不再是未触碰的盲样本。
