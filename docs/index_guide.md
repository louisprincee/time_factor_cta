# 股指策略

当前唯一注册策略是 [`index_clv_rally_base_long`](../strategies/index_clv_rally_base_long/index_clv_rally_base_long.json)，交易 IF、IH、IC。单位预算分两半：**底仓按 63/126/252 日绝对动量多数表决持有多头或空头；择时半仓沿用弱收盘 CLV 和冲高加仓。** 用户在 2026-11-04 确认了这一设计。状态仍是 `exploratory_predeclared`，没有冻结；本轮没有读取 2022–2025 样本外或 2026 数据。历史冻结的 `index_clv_rally_equal_up_long` 只保留原 JSON，退出注册，不改参数。

## 底仓为什么改，以及怎样改

原 MACD(12,26,9) 用 DIF 相对信号线的方向决定多空。DIF 是两条指数均线之差，柱是 DIF 减去它自己的平滑值，更接近趋势强弱的变化，不等于中期累计收益的正负。价格仍上涨、上涨速度放缓，柱也可能转负。这不适合把底仓解释成“长期跟随市场方向”。这是信号含义与目标不一致，不是 MACD 公式算错。

替代底仓的经济假说是**信息逐步进入价格、投资者逐步调整头寸，使中期收益存在延续**。[Moskowitz、Ooi、Pedersen（2012）](https://docs.lhpedersen.com/TimeSeriesMomentum.pdf) 在多类国际期货上发现自身过去收益对之后收益的预测，持续期大致在 1–12 个月。它支持研究中期绝对动量，不能直接证明国内三个高度相关股指上的趋势溢价，也不是“所有人反应慢”的因果识别。本实现每日更新、先汇总三品种再投票，并非论文逐品种月度策略的原样复刻。

单一 12 个月方向规则更简单，但依赖一个长度、转向更慢；用户选择 3/6/12 个月近似交易日的多数表决，避免一个窗口完全决定底仓。**三个长度作为一个预先固定的组合，没有分别回测后挑赢家。** 它们高度重叠，不是三份独立证据，也不是对急涨急跌的预测器。

1. 品种日收益为 `(closew[t]−closew[t−1])/close[t−1]`，IF/IH/IC 等权得到 `r[t]`。各窗口动量为过去 63、126、252 笔完整收益的 `prod(1+r)−1`。复权价是加法口径，不能直接计算复权价百分比变化。
2. 每个完整窗口累计收益严格大于 0 投多头票，否则投空头票，恰好 0 也为空头。至少两票为多，底仓 +0.5；否则 −0.5。信号可用当日已形成的收盘，下一开盘执行。
3. 未满窗口的票先投多头。这是公开的股票多头先验，不是观察到上涨。第一日没有上一收盘，不补成零收益。因此最早需 126 笔实际收益才可能出现两张空头票；第一年不具备完整的三周期保护。研究与样本外若将来获准运行，分别计算，不跨复权基准接收益。
4. 只替换底仓方向。CLV、冲高、等权、波动缩放、执行、整数手和停机不变；不加单边上涨、不按事件改方向。

中期趋势试图参与持续行情，短期反转试图在弱收盘后承接暂时性卖压，期限不同。二者在同一合约抵消：底仓 −0.5、CLV +0.5 时净目标为 0；再有冲高则加 +0.75，净目标为 +0.25。不能既要求底仓始终半仓，又忽略另半仓对它的抵消。慢信号会错过下跌开始，也可能在熊市急反弹中保留空头。[Daniel 和 Moskowitz（2016）](https://www.nber.org/papers/w20439) 提醒了动量崩溃风险；其主要对象是横截面动量，不能视为本策略验证或照搬其过滤。

## CLV 半仓：从假说到已有证据

CLV 为 `(closew−loww)/(highw−loww)`，三品种等权平均。pooled CLV < 0.4 时加 +0.5 多头，否则不加。它描述收盘在当天区间中的位置，不等于当天涨跌幅；高开回落也可能是弱收盘。

可能的传导链是：**短期卖出需求使价格偏弱 → 流动性提供者承接并承担库存风险 → 卖压衰减或跨时段客户换手后价格修复 → 下一开盘进入的反转仓位获得尚未完成的一段补偿。** [Nagel（2012）](https://www.nber.org/papers/w17653) 提供短期反转和流动性补偿框架；[Lou、Polk、Skouras（2019）](https://personal.lse.ac.uk/polk/research/TugOfWar.pdf) 说明隔夜与日内客户群可以产生持续与跨时段反转。这些是解释候选，不是 IF/IH/IC 上已经识别出的付款人。

下表来自已有研究结果，**本轮没有重跑机制检验**：

| 环节 | 已有观察 | 能得出的结论 |
|---|---|---|
| 弱收盘之后的收益 | 2015–2021：执行日开盘到下一开盘收益对前日弱收盘虚拟变量的系数 +23.74bp，NW t 3.03，逐年系数 7/7 为正，1,636 个回归观察 | 样本内关联成立；这是弱收盘减其余日的毛收益差，不是策略净收益 |
| 早期复制 | 2011 至 IH/IC 上市前的 IF：−0.65bp，t −0.07，3/5 年为正 | 没有复制；单品种与三品种也不完全可比 |
| 买卖价反弹 | 中间价 CLV 斜率仍为负，t −2.71 | 不支持全部只是买卖价反弹；没有排除所有微观结构影响 |
| 何时兑现 | 弱收盘后期货：开盘→09:31 +3.72bp（t 5.13），09:31→收盘 +3.70bp（t 0.64），该收盘→再下一开盘 +12.38bp（t 4.16） | 集中于第一分钟和持有日后的隔夜；“09:31 后盘中本身显著”的登记判定失败 |
| 现货与基差时序 | 现货隔夜继续低开（CLV 斜率 t +3.1），10:00 后反弹（t −4.3，6/6 年）；期货相对现货的基差修复几乎全在信号日后隔夜（t −8.8） | 信号日收盘至进场开盘的基差修复，不能算策略赚到的收益；现货、期货窗口不同 |
| 谁在承接 | 前 20 名会员弱收盘日净多增加（t −5.8；2016 起 −6.4），次日卖出（t +2.9；2016 起 +4.9） | 与承接相容，不支持大会员先加空再回补；会员汇总许多客户，无法识别账户 |
| 没接住的压力 | 会员同时卖出时 CLV 斜率约 −43bp（t −2.8），买入时约 +8bp，两组差不稳定；增仓/减仓反弹差 t 约 0.7 | 没有可以下单的数量条件 |
| 融资和北向 | 融资偿还更多（t −7.6），但偿还×CLV t −0.10；偿还最多组次日盘中约 6bp，最少组 11bp。北向卖出后没有独有的反转增强 | 卖压共现，不等于造成了可赚的修复 |
| 风险补偿预测 | 可交易开盘段收益对波动分位 t 0.63；QVIX×CLV 在 2016 起 t −2.16，含 2015 为 −0.88，分组不单调 | 完整样本没有稳健通过，不能据此增加恐慌仓位 |

[Qiao 和 Dam（2020）](https://research.rug.nl/en/publications/the-overnight-return-puzzle-and-the-t1-trading-rule-in-chinese-st/) 将 A 股隔夜折价与 T+1 联系起来；期货和股票约束不同。这提供时段差异的背景，不能推出“开盘半小时必有 T+1 抛压”：我们自己的半小时检验没有支持该预测。前 20 名会员约覆盖六到七成持仓，2015–2019 还有不同开仓限制，账户解释不完整。

目前可以说：**研究期弱收盘预测后续期货开盘段偏强；暂时性压力和流动性补偿是相容解释，具体渠道与对手方未识别。** 不应把现货、期货、基差和不同起点的显著 t 拼成已经实证完成的因果链。0.4 曾与 0.3、0.5 在同一研究期比较后选出；7/7 年关联也不是独立发现。

## 冲高与风控怎样接在这条链上

冲高为 `(highw−openw)/open`，用此前 60 日、至少 40 日均值和标准差计算 z，基准不含当日。z>0 只把 CLV 半仓从 +0.5 放大到 +0.75。它不是冲高就买；强收盘不会因此增加择时仓位。

同样弱收盘，白天曾明显上冲再回落，可能表示更多分歧或库存转移，需要更多承接补偿；也可能是利空重估、振幅或 beta，**唯一经济渠道并未识别**。历史自适应阶梯“核心加冲高”的逐日净收益差折成年化 +3.34 个百分点，NW t 3.69，6/7 年为正；完整历史账本去一法为 +3.66 个百分点，t 2.88，6/7 年为正。这是同一批行情的两种拆法，不是两次独立验证，也不是当前双半仓版本的冲高增量。更早研究提示收益集中在少数日子。本轮保留现有冲高，不重新挑门槛或倍数。

波动缩放是风险管理：截至信号日开盘已完成的 20 段开盘收益估计 RV20，两半净额乘 `min(1,20%/RV20)`，预热不足为 1。“高波动减仓”与“恐慌时反转补偿更高”是不同命题，不能混用。全账户回撤 10% 后清仓停 10 个交易日，是既有路径风控，不保证实际最大回撤严格止于 10%。QVIX 开关、量价过滤、单边形态没有恢复。

## 执行与复现

最终目标为 `scale × (0.5×多数表决方向 + 0.5×1{CLV<0.4}×冲高乘数)`。方向 ±1，乘数 1 或 1.5；缩放前净目标可为 −0.5、0、+0.25、+0.5、+1、+1.25。单位预算 1 是名义换算基准，不是将冲高目标截到 1 的硬上限。三品种目标相同，各除以 3 下整数手，目标变化才调整；实际敞口受取整、价格漂移、限额和停机影响。

初始资金 1000 万，历史交易所费率×1.01 并加每手 0.01 元，开盘后 30 分钟 L1 成本估计与既有换月口径；缺费用、tick、乘数或必要报价报错。保留逐日开仓限额。研究输入止于 2021-12-31，计分至 2021-12-30，最后一日开盘仅结算上一段。

```bash
python -m backtest.engine --market index --research
python -m research.index.index_adaptive_attribution --base-momentum
```

登记和批准设计见 [`index_base_momentum.json`](../config/research/index_base_momentum.json)。顺序为：合成测试先验证预热、零收益票、多数表决和执行滞后；替换底仓；运行新规则和两个已知底仓对照；核对正式 engine 的目标、逐日权益、费用和收益；全套测试和源码审查。只有一个新组合，无单周期网格。两半毛归因是风控前目标乘开盘段收益，不含费用、整数手和停机，不能当成两本独立净账。

预先登记的描述门槛（Sharpe 更高、回撤不更差、最差年度不更差）通过。**统计增益门槛未通过**：新规则减 MACD 日均净收益差 +1.03bp，NW(10) t **0.64**，5/7 年差为正；减常驻多头 t −1.24，2/7 年差为正；减买入持有 t 0.70。+2.48 个百分点是每日差值的算术年化，不能与两条几何年化之差混用。

底仓含义更符合中期方向目标，样本内持仓率提高、翻向减少、最差年度改善；**没有证明动量带来超额，也未实现每年为正**。2016 年新底仓毛诊断为负，2019 年收益低于常驻多头，慢趋势有迟滞和机会成本。2021 年两半风控前毛诊断为正，净账仍为负，费用、取整和路径不能略去。此前看过的 EMA20/60 空仓开关为 13.25%/1.35/−9.96%，无底仓 CLV 冲高为 18.21%/1.63/−9.13%；没有重新纳入收益选优，不能称本版本是所有历史候选中最好的。
