# 股指冻结策略

`index_clv_rally_fixed_long` 是 `--market index` 的默认策略，原有规则和冻结文件不变。2026-11-03，用户另行要求冻结两套比较策略：**股指单品种弱收盘活跃等权多头**（`index_clv_individual_equal_long`）与 **股指汇总弱收盘等权多头**（`index_clv_pooled_equal_long`）。三本规则不同，新策略均不替换默认项。商品策略不变。

## 规则

1. IF/IH/IC 的 `(closew-loww)/(highw-loww)` 等权平均，严格小于0.4则次日开盘做多，否则空仓；不做空，不再按展期率动态换权。
2. 每个品种的冲高 `(highw-openw)/open` 相对此前60日均值和标准差z化，至少40日，三品种z等权；信号日z>0则多头预算乘1.5，其余和特征未知时乘1。滚动窗口排除当前日。
3. 收盘已知的过去20个已完成开盘到开盘段的等权收益估计年化波动，乘数 `min(1,0.20/RV20)`；预热不足时1。方向、冲高、波动均下一开盘执行。
4. 固定IF/IH/IC相对乘数为0.891744548286604、0.623831775700935、1.484423676012461，目标预算份额约29.72%/20.79%/49.48%。来源是研究期642个计划多头日的展期排名乘数均值，不按收益优化，但使用了全研究样本分布，属于事后选择。冻结后不重估。
5. 名义预算=`目标权重×当日期初权益/3`；波动和冲高决定总预算，固定乘数只分配预算。1000万元初始资金，整数手，目标不变保持旧手数，不每日强制再平衡。实际敞口可能因价格变化偏离目标。
6. 保留10%账本峰值回撤清仓、停10个交易日、20%保证金假设和逐日中金所开仓限额。开盘腿采用连续交易前30分钟L1卖一/买一成本；换月旧约前收一跳，加历史手续费。旧连续价换月仍为近似，不是逐合约交易所结算重放。

规格：[`index_clv_rally_fixed_long.json`](../strategies/index_close_location/index_clv_rally_fixed_long.json)；实现：[`index_close_location`](../strategies/index_close_location/__init__.py)。

## 新增比较策略：单品种信号、活跃品种等预算

1. IF/IH/IC 分别计算自身 `CLV=(closew-loww)/(highw-loww)`；某品种 CLV 严格小于0.4，就在下一开盘对该品种做多。没有任何信号则空仓。
2. 只在当日有信号的品种间等分总预算：一个品种触发就独享基础预算，两个各一半，三个各三分之一。不会先求三个品种的平均CLV。
3. 保留原策略的共同冲高 z 放大（z>0 时总预算乘1.5）、20日波动缩放、10%回撤熔断停10日、1000万元初始资金、L1 30分钟执行和开仓限额。
4. 账本目标权重以三品种为固定分母：活跃品种的基础权重合计为2，敞口参数为1.5，因此名义预算为 `2×1.5/3=1.0` 倍期初权益；冲高放大时权重合计为3，预算最高为1.5倍，再由波动缩放下调。目标不变时不因权益或价格变化重新平衡。
5. 收盘信号在次日开盘生效；使用各品种自身 CLV，不使用 pooled CLV 门控。冲高因子仍为共同三品种序列。

规格：[`index_clv_individual_equal_long.json`](../strategies/index_clv_individual_equal/index_clv_individual_equal_long.json)；实现：[`index_clv_individual_equal`](../strategies/index_clv_individual_equal/__init__.py)。

### 研究期结果

2015-04-16 至 2021-12-30，连续账本；初始资金1000万元，历史手续费、L1 30分钟开盘成本、换月旧约一跳及中金所开仓限额。所有结果均来自已看过的研究期，不是独立样本外验证。

| 年份 | 净收益 | Sharpe |
|---|---:|---:|
| 2015（部分年度） | 12.17% | 1.12 |
| 2016 | 12.99% | 1.06 |
| 2017 | 10.78% | 1.01 |
| 2018 | −14.28% | −0.96 |
| 2019 | 36.16% | 2.15 |
| 2020 | 33.41% | 2.43 |
| 2021 | 4.12% | 0.42 |

全期累计净收益127.64%，年化净收益12.93%，Sharpe 1.00，最大回撤−19.42%，最大名义敞口1.53倍。与旧策略研究期账本（年化19.83%、Sharpe1.69、最大回撤−9.61%）相比，新策略回报较低、回撤更深；它在2018年亏损，不能把各自信号和等分预算视为已证实的改善。此对照同时改变了信号聚合与品种权重，不能拆分归因。

## 新增比较策略：汇总信号、IF/IH/IC等权

1. 先分别计算 IF/IH/IC 的 `CLV=(closew-loww)/(highw-loww)`，再取三者等权平均；均值严格小于0.4时，三个品种在下一开盘同时做多，否则全部空仓。
2. 触发时三个目标权重相同，基础名义预算合计为期初权益；不会按单品种信号挑选或调整活跃品种。
3. 保留共同冲高 z>0 时预算乘1.5、过去20个已完成开盘段的波动缩放、10%回撤熔断并停10日，以及1000万元、L1 30分钟执行、历史手续费和逐日开仓限额。
4. 目标权重合计为3，敞口参数为1.0；账本按 `目标权重×敞口参数×期初权益/3` 分配预算。冲高放大时总名义敞口最高约1.5倍，波动缩放可下调。目标不变时不因权益或价格变化重新平衡。
5. 该规则与单品种活跃等权策略的差别仅在信号聚合和预算是否给所有品种：本策略先对CLV求平均，并在一个共同信号下始终同时持有三个品种。

规格：[`index_clv_pooled_equal_long.json`](../strategies/index_clv_pooled_equal/index_clv_pooled_equal_long.json)；实现：[`index_clv_pooled_equal`](../strategies/index_clv_pooled_equal/__init__.py)。

### 研究期结果

2015-04-16 至 2021-12-30 连续账本；2015为部分年度。初始资金1000万元，计入历史手续费、L1 30分钟开盘成本、换月旧约一跳及中金所开仓限额。结果属于已查看研究期，不是独立样本外验证。

| 年份 | 净收益 | Sharpe |
|---|---:|---:|
| 2015（部分年度） | 16.96% | 1.92 |
| 2016 | 19.68% | 1.77 |
| 2017 | 15.39% | 2.09 |
| 2018 | 11.47% | 0.85 |
| 2019 | 36.55% | 2.66 |
| 2020 | 27.68% | 2.36 |
| 2021 | −1.23% | −0.12 |

累计净收益210.03%，年化净收益18.21%，Sharpe 1.63，最大回撤−9.13%，最大名义敞口1.52倍。相较默认的固定品种权重策略（年化19.83%、Sharpe1.69、最大回撤−9.61%），该等权版本收益略低、回撤接近；相较单品种活跃等权版本（年化12.93%、Sharpe1.00、最大回撤−19.42%），本版本研究期数字更高。各策略均复用已查看的2015–2021数据，且比较同时涉及信号汇总与持仓覆盖差别，不构成独立验证或因果归因；2021年为负收益。

## 逐年结果与稳定性

2015-04-16..2021-12-30连续账本，最后一段结算到2021-12-31开盘；2015不是完整自然年。年度收益按持有段执行日归年，年度Sharpe用该年日净收益计算，每年242日年化。不是每年重置资金另跑。

| 年份 | 净收益 | Sharpe |
|---|---:|---:|
| 2015 | 15.53% | 1.64 |
| 2016 | 26.39% | 2.22 |
| 2017 | 14.96% | 1.87 |
| 2018 | 11.31% | 0.82 |
| 2019 | 38.56% | 2.63 |
| 2020 | 30.77% | 2.56 |
| 2021 | 0.40% | 0.09 |

整段年化净收益19.83%，年化波动11.07%，Sharpe1.69，最大回撤−9.61%，Calmar2.06。10个既有候选中它是唯一7/7年净收益为正；但年收益0.40%–38.56%、年度收益标准差12.95个百分点，仍有明显起伏。2021年几乎没有收益，不能把“年年为正”解释为稳定高收益，更不能保证未来每年盈利。无冲高的等权多头年度标准差较低（9.81个百分点），但2021年为负，不满足用户优先条件。

## 新增冻结策略：20日收益排名与逆波动率配置

两本策略沿用 pooled CLV<0.4、冲高z>0时总预算乘1.5、20日组合波动缩放、1000万元初始资金、L1 30分钟开盘执行、整数手、逐日开仓限额和10%/10日熔断，只改变IF/IH/IC间的预算分配。收益排名用最近20日相对收益的横截面平均秩分配总乘数3；逆波动率用最近20个收盘收益的样本标准差倒数分配总乘数3，单品种乘数上限2并按剩余逆波动率权重重分配。交给账本的目标权重是这些乘数乘上当日预算，合计为 3 倍当日预算；账本再按品种数 3 去除，策略内部不再除。估计不足时等权；OOS动态估计只使用OOS窗口内的收益，不拼接研究期和OOS复权价基准。最后一个研究日已经算好的波动缩放仍用于下一个开盘。

规格与实现：[`index_clv_return_rank_20d_long`](../strategies/index_clv_return_rank_20d/) 和 [`index_clv_inverse_vol_20d_long`](../strategies/index_clv_inverse_vol_20d/)，共享分配逻辑在 [`index_allocation.py`](../strategies/index_allocation.py)。样本外分区已准备，尚未回测。

## 经济解释与证据边界

- **弱收盘反转**：暂时性卖压可能让价格偏离短期价值，之后修复。[Nagel《Evaporating Liquidity》](https://www.nber.org/papers/w17653)为短期反转与流动性供给提供理论及实证背景。本仓库L1发现弱收盘伴随价差扩大、部分深度变薄，但没有稳健证明这就是反转的原因。价差弹跳解释已被现有研究拒绝；原因仍未被因果识别。
- **冲高加仓**：相同弱收盘下，日内曾交易在更高位置可能表示更大的暂时价格位移，因此只加预算；但此前收益集中于少数日期，早期IF的相对改善部分来自熔断路径。这是较弱的事后证据，不是新的独立因子确认。
- **固定偏配IC**：来自展期排名的平均分布，动态权重没有超越固定倾斜，不能把增益认定为“动态收割展期收益”。主力对远月曲线斜率也不是期货对现货贴水，风格与风险暴露解释仍然存在。
- **无空头及波动缩放**：删除空头避免下跌后急反弹的方向风险，也放弃单边下跌收益。波动缩放、熔断用于管理风险，并不创造收益或保证小回撤。

## 研究期运行

```bash
python -m backtest.engine --market index --research
python -m backtest.engine index_clv_rally_fixed_long --research
python -m backtest.engine index_clv_individual_equal_long --research
python -m backtest.engine index_clv_pooled_equal_long --research
python -m backtest.engine --market index --oos
python -m backtest.engine index_clv_return_rank_20d_long --start 2022 --end 2025
```

不点名时，`--market index` 按注册表把五本都跑完；点名只跑那一本。默认规则仍是固定权重那本。账本在 `runs/index/strategies/<strategy>/<区间>/`，净值图同时画等权买入持有。`--research` 是 2015–2021，`--oos` 是 2022–2025。固定1000万元、`l1_30m`执行和历史手续费不代表实盘优势。旧候选的研究结论保留在 [`index_research_review.md`](index_research_review.md)。

两套新增规则是在研究结果已被反复查看的背景下冻结；固定乘数及新增规则的选择都不构成干净OOS验证。
