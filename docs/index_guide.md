# 股指策略

当前唯一注册策略是 [`index_clv_rally_base_long`](../strategies/index_clv_rally_base_long/index_clv_rally_base_long.json)，交易 IF、IH、IC。用户在 2026-11-04 确认：**21/63/126 日上涨窗口数量决定 0 至半仓的多头底仓，释放的预算交给 CLV；完全不做空。** 冲高仍只放大 CLV，风控前总目标最高 1.5 倍。状态仍为 `exploratory_predeclared`，不冻结，不读 2022–2025 样本外或 2026 数据。历史冻结的 `index_clv_rally_equal_up_long` 原 JSON 保留、退出注册。

## 确认后的预算分配

品种收盘收益为 `(closew[t]−closew[t−1])/close[t−1]`，三品种等权得到 `r[t]`。加法复权价必须先取差，再除以原始上一收盘，不能直接对复权价算百分比变化。分别计算过去 21、63、126 笔完整收益的 `prod(1+r)−1`，对应约 1/3/6 个月。

每个窗口严格为正投一张多头票，零或负不投。底仓预算 `b=0.5×多头票数/3`，CLV 可用预算为 `1-b`。信号在当日收盘已知，下一开盘执行。

| 上涨窗口数 | 多头底仓预算 b | CLV 可用预算 | CLV弱收盘且冲高后的总目标（缩放前） |
|---|---:|---:|---:|
| 3 | 50% | 50% | 125% |
| 2 | 33.33% | 66.67% | 133.33% |
| 1 | 16.67% | 83.33% | 141.67% |
| 0 | 0% | 100% | 150% |

没有 CLV<0.4 信号时，CLV 预算留现金，即使底仓已为零也不会无条件满仓。完整目标为 `scale × [b + (1-b)×1{CLV<0.4}×rally_multiplier]`。冲高乘数为 1 或 1.5；无冲高且出现 CLV 时，缩放前总目标恰为 1。三品种等权，不加品种择时或新过滤。

未满窗口沿用多头票先验，第一日没有上一收盘，不补成一笔零收益。最早需 21 笔真实收益才减第一档、126 笔才有完整三窗口。预热多票不代表已观测到上涨。未来获准的样本外仍需按分区单独算收益，不能跨复权基准。

## 底仓和反转的经济角色

多头底仓用于参与持续上涨；短中期自身收益转弱时，逐级减少股票方向风险。[时间序列动量研究](https://docs.lhpedersen.com/TimeSeriesMomentum.pdf) 支持研究自身收益的延续，但本实现是三品种汇总、每日分档的多头风险预算，并非论文策略的原样复制，也没有证明国内股指动量溢价。没有做空，避免了趋势空头抵消 CLV 多头；代价是在下跌时失去空头保护。

CLV 承接短期弱收盘后的反转；减少底仓后把预算转给 CLV，并不意味着整体必然更安全：熊市里的弱收盘反转可能继续下跌，动态分配会加大该时刻的反转仓位。这是需要报告的风险取舍，不是通过调门槛消除的风险。

此前 MACD 柱衡量的是 DIF 相对平滑值的变化，上涨放缓也可能转负；后来 63/126/252 多数表决把底仓设为 ±0.5。当前按用户确认取消空头、缩短为 21/63/126 并逐档配置，旧版本及其结果保留在历史研究说明和研究对照，不能把反复看过的样本当独立验证。

## CLV：从假说到已有证据

CLV 为 `(closew−loww)/(highw−loww)`，三品种等权平均。pooled CLV < 0.4 时启用剩余预算 `1-b`，否则这部分留现金。它描述收盘在当天区间中的位置，不等于当天涨跌幅；高开回落也可能是弱收盘。

可能的传导链是：**短期卖出需求使价格偏弱 → 流动性提供者承接并承担库存风险 → 卖压衰减或跨时段客户换手后价格修复 → 下一开盘进入的反转仓位获得尚未完成的一段补偿。** [Nagel（2012）](https://www.nber.org/papers/w17653) 提供短期反转和流动性补偿框架；[Lou、Polk、Skouras（2019）](https://personal.lse.ac.uk/polk/research/TugOfWar.pdf) 说明隔夜与日内客户群可以产生持续与跨时段反转。这些是解释候选，不是 IF/IH/IC 上已经识别出的付款人。

下表来自已有研究结果，**本轮没有重跑机制检验**：

| 环节 | 已有观察 | 能得出的结论 |
|---|---|---|
| 弱收盘之后的收益 | 2015–2021：执行日开盘到下一开盘收益对前日弱收盘虚拟变量的系数 +23.74bp，NW t 3.03，逐年系数 7/7 为正，1,636 个回归观察 | 样本内关联成立；这是弱收盘减其余日的毛收益差，不是策略净收益 |
| 早期复制 | 2011 至 IH/IC 上市前的 IF：−0.65bp，t −0.07，3/5 年为正 | 没有复制；单品种与三品种也不完全可比 |
| 买卖价反弹 | 中间价 CLV 斜率仍为负，t −2.71 | 不支持全部只是买卖价反弹；没有排除所有微观结构影响 |
| 何时兑现 | 弱收盘后期货：开盘→09:31 +3.72bp（t 5.13），09:31→收盘 +3.70bp（t 0.64），该收盘→再下一开盘 +12.38bp（t 4.16） | 集中于第一分钟和持有日后的隔夜；“09:31 后盘中本身显著”的登记判定失败 |
| 现货与基差时序 | 现货隔夜继续低开（CLV 斜率 t +3.1），10:00 后反弹（t −4.3，6/6 年）；期货相对现货的基差修复几乎全在信号日后隔夜（t −8.8） | 信号日收盘至进场开盘的基差修复，不能算策略赚到的收益；现货、期货窗口不同 |
| 谁在承接 | 前 20 名会员弱收盘日净多增加（t −5.8；2016 起 −6.4），次日卖出（t +2.9；2016 起 +4.9） | 与承接相容，不支持大会员先加空再回补；会员汇总许多客户，无法识别账户 |
| 没接住的压力 | 会员同时卖出时 CLV 斜率约 −43bp（t −2.8），买入时约 +8bp，两组差不稳定；增仓/减仓反弹差 t 约 0.7 | 没有可以下单的数量条件 |
| 融资和北向 | 融资偿还更多（t −7.6），但偿还×CLV t −0.10；偿还最多组次日盘中约 6bp，最少组 11bp。北向卖出后没有独有的反转增强 | 卖压共现，不等于造成了可赚的修复 |
| 风险补偿预测 | 可交易开盘段收益对波动分位 t 0.63；QVIX×CLV 在 2016 起 t −2.16，含 2015 为 −0.88，分组不单调 | 完整样本没有稳健通过，不能据此增加恐慌仓位 |

[Qiao 和 Dam（2020）](https://research.rug.nl/en/publications/the-overnight-return-puzzle-and-the-t1-trading-rule-in-chinese-st/) 将 A 股隔夜折价与 T+1 联系起来；期货和股票约束不同。这提供时段差异的背景，不能推出“开盘半小时必有 T+1 抛压”：我们自己的半小时检验没有支持该预测。前 20 名会员约覆盖六到七成持仓，2015–2019 还有不同开仓限制，账户解释不完整。

目前可以说：**研究期弱收盘预测后续期货开盘段偏强；暂时性压力和流动性补偿是相容解释，具体渠道与对手方未识别。** 不应把现货、期货、基差和不同起点的显著 t 拼成已经实证完成的因果链。0.4 曾与 0.3、0.5 在同一研究期比较后选出；7/7 年关联也不是独立发现。

## 冲高与风控怎样接在这条链上

冲高为 `(highw−openw)/open`，用此前 60 日、至少 40 日均值和标准差计算 z，基准不含当日。z>0 只把动态 CLV 预算乘 1.5；牛市是 +0.5 放大到 +0.75，底仓为零时是 +1 放大到 +1.5。它不是冲高就买；强收盘不会因此增加择时仓位。

同样弱收盘，白天曾明显上冲再回落，可能表示更多分歧或库存转移，需要更多承接补偿；也可能是利空重估、振幅或 beta，**唯一经济渠道并未识别**。历史自适应阶梯“核心加冲高”的逐日净收益差折成年化 +3.34 个百分点，NW t 3.69，6/7 年为正；完整历史账本去一法为 +3.66 个百分点，t 2.88，6/7 年为正。这是同一批行情的两种拆法，不是两次独立验证，也不是当前双半仓版本的冲高增量。更早研究提示收益集中在少数日子。本轮保留现有冲高，不重新挑门槛或倍数。

波动缩放是风险管理：截至信号日开盘已完成的 20 段开盘收益估计 RV20，两半净额乘 `min(1,20%/RV20)`，预热不足为 1。“高波动减仓”与“恐慌时反转补偿更高”是不同命题，不能混用。全账户回撤 10% 后清仓停 10 个交易日，是既有路径风控，不保证实际最大回撤严格止于 10%。QVIX 开关、量价过滤、单边形态没有恢复。

## 执行与复现

常规预算基准为 1 倍，冲高后目标上限为 1.5 倍。三品种目标相同，再各除以 3 下整数手。底仓是风控、取整前预算，**没有实际持仓至少 50% 的约束**。目标不变继续持有原手数，不因价格或权益变化每天重新配满；实际敞口可漂移，1.5 倍是目标边界，不是逐时硬上限。

初始资金 1000 万，历史交易所费率×1.01 并加每手 0.01 元，开盘后 30 分钟 L1 成本估计与既有换月口径；缺必要成本报错。RV20 用截至信号日开盘已完成的 20 段收益，缩放上限 1；回撤达到 10% 后按下一可交易开盘清仓并停 10 个交易日。跳变和执行时点可能使实际回撤超过 10%。研究输入止于 2021-12-31，最后计分为 2021-12-30。

相对上一多空版，日均净收益差 +2.28bp、NW(10)t **2.45**，6/7 年差为正，达到本次登记的样本内增益门槛；相对常驻多头 t 1.75，4/7 年差为正；相对买入持有 t 1.80，6/7 年差为正。都是同一反复研究样本，不能视为独立验证。**整体改进标准没有通过：虽然平均敞口和 Sharpe 提高，最大回撤从 −10.30% 加深到 −14.50%。** 2021 仍亏损，不满足每年为正。

## 52.47% 平均仓位的逐日审计

旧“常驻半仓多头”指分配一半信号预算，不是让实际名义持仓始终达到权益的 50%。其 1,637 日名义金额都能由实际手数×原始开盘×乘数复算；**1,081 个清洁调仓日**（前后不停机、前后无受阻/开仓限额、当日无实际换月）逐品种手数均与 `floor(target×期初权益/3/单手名义)` 一致，未发现这两条计算链出错。

| 同一常驻多头账本的层级 | 全期平均 |
|---|---:|
| 未缩放底仓目标 | 49.97%（首日目标为零） |
| 未缩放CLV目标 | 21.37% |
| 未缩放总目标 | 71.33% |
| 波动缩放后总目标 | 62.78%（底仓44.11%＋CLV18.67%） |
| 按实际停机日置零后的总目标 | 62.35% |
| 假设以每日当时期初权益重新向下取整 | 52.47% |
| 实际持仓、期初权益分母 | 52.51% |
| 实际持仓、期末权益分母（原报告口径） | **52.47%** |

主要差额来自波动缩放和整数手，而不是 CLV 只用了 2.47%。例如假设 1000 万资金、每品种单手名义都是 120 万，50%预算分给三品种后各有166.7万，只能各买1手，合计实际36%，不会达到50%。这是整数手规则的结果。

表中“每日重新取整”是同一实际权益路径上的诊断，不是一条独立回测；它与实际持仓的差额还包含目标不变保持手数、限额、受阻和换月影响，各层差值不能称为独立因果效应。若按目标比例约定分摊，旧账实际敞口约为底仓35.90%＋CLV16.56%，两者并没有独立实际手数，分摊不是唯一的。

新规则也通过了1,637日名义复算和1,104个清洁调仓日手数核对。其缩放后目标56.08%、停机后55.79%、每日重算整数手47.99%、实际期初口径48.07%、期末口径48.02%。底仓减仓后释放的是预算，CLV无信号仍留现金，所以不会自动达到满仓。
