# 股指策略研究：从日内因子到当前规则

## 当前结论与策略

当前唯一保留的策略是 `index_clv_rally_base_long_2x`，交易 IF、IH、IC。它是在 2015—2021 研究样本上形成并冻结的研究版本，不是经过独立样本外验证的实盘策略。

先说结论。研究期里最站得住的是一个统计规律：三个股指一起收在当天区间的低位之后，下一段（下一开盘到再下一开盘）平均偏强。它不是买卖价反弹造成的，在商品期货上也能看到同样的现象。但它在 2015 年以前的 IF 上不成立，我们也没能证明它到底是谁在为这部分收益"买单"。冲高放大有一定证据；趋势底仓和 2 倍乘数是参与度和风险之间的取舍，研究期里没有统计上的证据说明它们改善了风险收益。

策略由趋势底仓和 CLV 反转预算两部分组成：

1. **趋势底仓：** 计算 IF、IH、IC 等权收盘收益的 21、63、126 日复利收益。每个完整窗口收益严格为正，投一张多头票；负或为零不投。底仓预算为 `0.5 × 正收益票数 / 3`，所以最多半仓。窗口尚未完整时暂按多头票处理。
2. **CLV预算：** `CLV=(收盘价−最低价)/(最高价−最低价)`。三品种等权平均低于 0.4 时，将剩余预算用于多头；否则剩余预算留现金。
3. **冲高放大：** 当日最高价相对开盘价的涨幅，用此前 60 日数据标准化（至少 40 日）。标准化结果大于 0 时，只将 CLV 预算乘 2，不放大趋势底仓。

| 正收益趋势窗口数 | 趋势底仓 | CLV预算 | 弱收盘、非冲高：缩放前总目标 | 弱收盘、冲高：缩放前总目标 |
| ---------------: | -------: | ------: | ---------------------------: | -------------------------: |
|                3 |      50% |     50% |                         100% |                       150% |
|                2 |   33.33% |  66.67% |                         100% |                    166.67% |
|                1 |   16.67% |  83.33% |                         100% |                    183.33% |
|                0 |       0% |    100% |                         100% |                       200% |

上表是目标预算，不是保证实际持仓达到的仓位。收盘信号在下一交易日开盘执行，三品种等权、不做空；实际交易还受 20 日波动缩放、整数手、开仓限额、成本及回撤停机影响。回测起始资金 1,000 万元，执行采用 L1 开盘后 30 分钟口径；波动目标为年化 20%、缩放上限为 1，回撤达到 10% 后停交易 10 个交易日。

冻结版研究期总体结果如下。等权买入持有（BH）使用同一研究日历、同一成本口径作为比较，不代表策略可以无成本复制。

## 研究过程

### 一、先检验研报中的日内时间因子

研究起点是国泰君安期货 2025 年的股指时间因子报告：日内高低点出现的时间、成交活动的时间、价格在某些位置停留多久，是否包含下一段收益的信息。我们做了两项检查。

**第一项：复现报告的 23 条双因子规则。** 在 IF、IH、IC 上，2016-01-04 至 2021-12-30，扣手续费和每边一跳。报告为各品种挑出的规则，在本品种上平均净 Sharpe 只有 0.19；IH 的规则在 IH 上多数为负。表现较好的几条和 CLV 反转信号的相关系数在 0.3—0.5 之间。控制当日 CLV 之后，没有一个规则单元的 t 值达到 2（最高 1.69）；反过来，控制任何一条规则后，CLV 在 IF、IC 上仍然显著。复现脚本当时没有提交进仓库，这组结果来自当时的研究记录。

**第二项：单因子筛查。** 对 14 个时间戳和停留价格因子逐个检验，信号日 2016—2021，结果变量是次日开盘到再下一开盘的收益，t 值是单品种时间序列回归的 HAC t（5 阶）。"控制后"指同时放入当日涨跌、收盘在当日区间的位置和对数成交量。下表列出其中 10 个，展示控制前后的变化。它是筛选阶段的诊断表，不是因子策略收益的排名。

| 日内因子（示例）                      | IF 单因子 t → 控制后 | IH 单因子 t → 控制后 | IC 单因子 t → 控制后 |
| ------------------------------------- | --------------------: | --------------------: | --------------------: |
| 全天低点时点 `ts_low`               |          1.95 → 0.52 |          1.67 → 0.81 |          1.75 → 0.09 |
| 下午低点时点 `ts_low_pm`            |          3.00 → 1.28 |          2.53 → 1.94 |        1.96 → −0.21 |
| 全天高点时点 `ts_high`              |        −0.26 → 2.03 |        −0.41 → 1.07 |        −1.37 → 0.75 |
| 上午高点时点 `ts_high_am`           |          1.23 → 1.89 |          0.41 → 1.17 |          1.13 → 1.56 |
| 下午高点时点 `ts_high_pm`           |        −1.52 → 0.79 |        −0.20 → 1.03 |        −2.11 → 0.35 |
| 停留时间最长三个价格点 `dfp_top3`   |          2.14 → 1.17 |        0.60 → −0.02 |          2.48 → 1.60 |

事先定的完整门槛是：控制后 |t| ≥ 2，并且 6 年里至少 5 年方向一致。股指收盘决策下，只有 IC 的 `dfp_top3_fixed` 过了门槛（控制后 t 2.16，5/6 年），没有任何一对因子被允许组合。

单个品种、单个因子的 t 值不能代表稳健的横截面 IC，也没有因一两个局部显著结果就把它们加入策略。更重要的发现是：许多"时间"变量其实部分描述了价格最终收在日内区间的什么位置。低点出现得晚，往往就是收得低。于是研究主线转向更简单、可直接解释的收盘位置指标 CLV。

#### 高点出现时点：值得继续研究，但还不能直接加仓

这张表里有一个值得单独追问的现象：控制当日收益、收盘位置和成交量后，`ts_high` 的估计方向由负转正，IF 的 t 值达到 2.03；IH、IC 分别为 1.07、0.75。`ts_high_am` 控制后的估计方向也都为正，但 t 值分别为 1.89、1.17、1.56，尚未达到通常作为参考的 2。表中是控制前后回归系数的 t 值，不是策略收益或独立样本外检验。

这个变化可以作为一个**条件信息**的研究线索：在收盘位置和当日涨跌相近时，高点出现得较晚，可能描述了不同的日内价格路径，例如买方推动持续到较晚时段。它也可能只是相关变量共同进入回归后的抑制效应或共线性造成的符号变化；目前的 t 值不能区分这些解释。尤其 `ts_high` 的原始先验方向为负，控制后转正，应该先复核条件系数、样本稳定性和预测表现，而不是直接按新的正方向交易。

这两个变量在收盘时都可计算，因此从信号时点看，可以研究它们对下一交易日开盘后收益的增量预测。后续检验应先固定定义和方向，把 `ts_high`、`ts_high_am` 分别加入现有 CLV 基准，再检查是否需要与弱收盘交互；报告全部候选、年度方向、HAC 统计、逐年扩展预测表现和计入成本后的配对账本，并对多重检验作修正。不能只挑 IF 的 t=2.03，也不能因为加入变量后样本内 t 变大就认定策略改善。

#### 增量检验结果（2026-11-05）

看完筛查后，挑出三个控制后仍有 t 的因子，事先登记了一个增量检验（[`index_time_factor_increment.json`](../config/research/index_time_factor_increment.json)，`python -m research.index.index_time_factor_increment`）：`ts_low_pm`（先验 +）、`dfp_top3`（先验 +）、`ts_high`（不预设方向）。做法是把三个品种的因子、控制变量和收益等权平均，回归"下一开盘到再下一开盘收益 ~ 因子 + 当日涨跌 + 收盘位置 + 对数成交量"，HAC 5 阶，三个因子做 Holm 校正；再在 IH、IC 上市前的 IF 上复制。所有日内变量统一用 09:31—11:30、13:01—15:00 的时钟。2016 年起逐品种的因子、控制变量和收益与原筛查完全一致（最大差 0）。

| 因子 | 共同样本 t（Holm p） | 每 1 个标准差 | 逐年同号 | 只看弱收盘日 t | 早期 IF t（逐年同号） | 判定 |
| ---- | -------------------: | ------------: | -------: | -------------: | --------------------: | ---- |
| `ts_low_pm` 下午低点时点 | 1.50（0.40） | +8.7 bp | 5/7 | 0.67 | 2.49（5/5） | 不支持 |
| `dfp_top3` 停留最久价格偏离 | 0.41（0.72） | +2.7 bp | 3/6 | 0.49 | 0.65（3/5） | 不支持 |
| `ts_high` 全天高点时点 | 0.92（0.72） | +6.1 bp | 4/7 | 0.93 | 0.47（2/5） | 不支持 |

三个因子在共同样本上都没有过 Holm 校正，按事先写的规则都记"不支持"。把三个品种合在一起之后，筛查里单个品种较高的 t（`ts_low_pm` IH 1.94、`ts_high` IF 2.03）都缩小了，说明那些格子更多是单品种的噪声。只看策略真正交易的弱收盘日，三个因子也都不显著。唯一值得记下的是 `ts_low_pm` 在早期 IF 上反而较强（t 2.49，5 年同号），方向和"卖压集中在收盘前、次日修复"一致；但它在主样本上没过，而早期 IF 只有一个品种、弱收盘反转本身在那段也不成立，不能单凭它把这个因子加进策略。

**当前不把它们写入冻结策略。** 现有规则已冻结，任何实盘规则变化都需要新的策略 ID 和独立的用户决定。2015—2021 已被反复查看，只能用于有登记的探索性检验，不是新的验证样本；2022—2025 样本外尚未运行，也不能在没有明确授权时打开。

#### 按品种拆分：没有找到可用于差异化加仓的因子

另按预登记的 [`index_clv_cross_product_factors.json`](../config/research/index_clv_cross_product_factors.json)，只在当前市场 CLV<0.4 的交易日里，对每个品种分别检验三个因子在控制本品种当日收益、收盘位置和成交量后，是否还预测本品种下一段收益。9 个品种—因子检验统一做 Holm 校正：

| 品种 | `ts_low_pm` bp/SD (t) | `dfp_top3` bp/SD (t) | `ts_high` bp/SD (t) |
| ---- | -------------------: | ------------------: | -----------------: |
| IF | +3.3 (0.56) | +11.6 (1.41) | +3.9 (0.64) |

没有一个原始 p 值低于 0.05，Holm 校正后均为 1.00；逐年同号最多 4/6 年。`ts_high` 的估计大多为正，但幅度和 t 值都不足以支持加仓；IF/IC 的 `dfp_top3` 点估计较大，也没有显著性或年度稳定性。因而没有证据按品种挑因子、只在某品种的特定日子加仓，或把更多权重分给某个品种。这里的点估计不是应当直接采用的仓位系数。三个因子是从此前筛查中挑出的；9 项 Holm 校正并未消除前序 115 格筛选造成的选择偏差。

#### 纯择时与因子仓位倾斜候选（2026-11-05）

用户确认后，登记并实现了两个**未注册、未冻结**的研究候选（[预登记规格](../config/research/index_tactical_factor_candidates.json)）。仅运行 2015—2021 研究账本，没有读取样本外：

1. **纯 CLV 择时**：移除动量底仓；市场等权 CLV<0.4 时把全部择时预算分给三品种等权持有，冲高时择时预算×2。保留现有波动缩放、10% 熔断、开盘限制、研究期费用和 L1 滑点口径。
2. **因子仓位倾斜**：保留相同市场 CLV 总开关，CLV 信号触发时 IF/IH/IC 都参与。只使用弱收盘子样本里正向 t>1 的三个品种—因子格：IF `dfp_top3`（t=1.41）、IC `dfp_top3`（t=1.04）、IC `ts_high`（t=1.48）；因此 IF/IH/IC 有利票数上限为 1/0/2。每品种有利方向的滚动 z>0 计一票，每个品种先有 1 份基础预算，再按 `1+票数` 归一化倾斜预算。因子用截至前一日的 250 个历史观测标准化，缺失/预热不足按 0 票处理，因而不会阻止入场；没有有利票时自然等权。冲高倍数和风险控制同上。**这三个 t 值都未达到显著性；再按 t 选择还会增加事后筛选偏差，规则仅作为探索候选。**

### 二、CLV 与下一段收益的关系

CLV 越低，收盘越靠近当日低点。主要检验不是把信号日收盘到次日开盘的跳空算作收益，而是关注信号形成后可以执行的持有段。以三品种共同市场的弱收盘指标回归下一开盘到再下一开盘的收益，结果如下：

#### 等权信号和单品种 CLV（2026-11-05）

CLV 是各品种收盘在当日高低区间中的相对位置，值域一致，因此等权平均不受合约价格量纲影响。一个合理但有限的解释是：平均值代表市场弱收盘的广度，减少单一品种极端波动对信号的支配，也避免根据同一段历史收益挑品种权重；它不意味着三个品种独立，也不证明收益来自共同的经济机制。

| 每日序列两两相关 | IF–IH | IF–IC | IH–IC |
| --------------- | -----: | -----: | -----: |
| CLV | 0.888 | 0.798 | 0.598 |
| 下一段开盘收益 | 0.920 | 0.875 | 0.698 |
| 单品种 CLV<0.4 指示 | 0.734 | 0.631 | 0.448 |

共同样本 1,636 日中，三品种都弱收盘占 25.2%，都不弱占 46.2%，至少一个品种和其他品种的信号不一致占 28.5%。市场等权 CLV<0.4 的日子占 39.2%；其中 96.6% 的日子至少两个品种自己的 CLV 也低于 0.4。因此等权条件通常确实对应较广泛的弱收盘，而非单一品种单独触发。但收益相关高达 0.70–0.92，分散化有限，三品种不能算三份独立证据。

按各品种自己的 CLV<0.4 做信号，毛收益差（弱收盘日减非弱收盘日）如下；8 个预登记检验（4 个弱收盘差、4 个连续 CLV 斜率）统一做 Holm 校正：

| 信号品种 | 弱收盘日数 | 收益差 bp | HAC t | Holm p |
| -------- | ---------: | --------: | ----: | -----: |
| IF | 661 | +21.1 | 2.84 | 0.025 |
| IH | 688 | +12.7 | 1.66 | 0.261 |
| IC | 611 | +16.5 | 1.71 | 0.261 |
| 三品种等权 CLV | 642 | +23.7 | 3.03 | 0.020 |

校正后，单品种阈值信号只有 IF 显著；连续 CLV 斜率在 IF、IC 和三品种等权序列上显著为负，IH 不显著。故不能概括为“三个品种各自的 CLV 都显著”；组合信号的结果更稳定，但仍是同一研究期内的毛收益关系，没有扣除交易成本。这里的 8 项 Holm 校正没有覆盖先前的 0.3/0.4/0.5 阈值比较或其他历史探索，仍应视为探索性证据。

| 弱收盘相对其他日的收益差 |  +23.74 bp | 这是毛收益差，不是策略净收益                                  |
| Newey–West t 值         |       3.03 | 对收益序列相关作稳健误差处理后仍有统计证据                    |
| 逐年系数方向             | 7/7 年为正 | 表明关系不是只由某一个年度的系数符号驱动；不等于 7 次独立验证 |
| 回归观察数               |      1,636 | 共同样本主检验                                                |
| 低五分位减高五分位       |  约 +29 bp | 收盘位置更低的组，之后收益更强                                |

门槛曾比较 0.3、0.4、0.5：三者弱收盘收益差的 HAC t 值分别约 2.45、3.03、2.76。0.4 不是理论上唯一正确的界线；它是研究采用的工作阈值，必须连同阈值比较和样本选择背景一起理解。

几项稳健性检查：

- **收益集中在低收盘一侧。** 按 CLV 五分组看次日盘中收益，最低两组约 +14 bp（t 2.3、2.8）；中间组为负，最高组约 −6 bp、不显著。所以这是"收得低之后会修复"，不是"收得越高第二天跌得越多"。
- **和振幅无关。** 控制当日振幅后，收盘位置斜率变化很小；单独加入振幅没有解释力（t 约 0.13）。起作用的是收在区间里的相对位置。
- **商品期货上能复制。** 商品研究池 2011—2021 的等权 CLV，对下一交易时段盘中收益的斜率约 −32 bp/单位 CLV，t −4.21，11 年都为负。这是另一个市场、另一组参与者，而且覆盖了 2011—2015。
- **时间上不稳定，这是最大的疑点。** IH、IC 上市前的 IF（2011 至 2015 年 4 月），弱收盘的收益差约 −0.6 bp，t −0.07，基本为零。现货指数 2010—2015 也弱（t −1.09），但 2005—2010 的现货有同方向的反弹（事后拆分，约 −41 bp/单位 CLV，t −2.78）。也就是说，这个规律在股指上不是一直存在，2010—2015 现货和期货一起消失过。原因没有检验清楚。IF 的日成交量与持仓量之比，2015 年约 6 倍，2016 年降到约 0.4 倍，投机结构差别很大，但不能据此认定因果。

### 三、经济假设：哪些得到支持，哪些没有

机制假设是：短期卖压使价格偏弱 → 流动性提供者承接库存风险 → 卖压减弱或交易者换手后价格修复 → 下一开盘进入的反转仓位获得补偿。围绕这条链条，研究检查了价格、盘口、基差、会员持仓、融资与北向资金等。思路是：如果机制成立，每一环都应该留下可以检验的痕迹，而且卖压越大、风险越高，补偿应该越大。结果有局部支持，但没有识别完整的付款机制。

| 假设环节                   | 关键观察                                                                                      | 判断                                                                     |
| -------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 只是买卖价反弹             | 成交价与 L1 中间价算出的 CLV，对次日盘中收益的斜率几乎相同，t 分别约 −2.72、−2.71              | 不支持"全部只是收盘落在买卖价一侧"；仍不能排除所有微观结构影响         |
| 尾盘流动性压力             | 低收盘日尾盘相对价差更宽（差 0.033，t 6.60）、相对深度更薄（t −3.82）；CLV 与深度变薄的交互 t 约 −2.24，与价差的交互 t 约 −0.39 | 有压力共现和部分交互证据，但预登记的完整条件没有全部通过                 |
| 下一开盘卖压、随后盘中承接 | 用现货指数检验：开盘半小时收益对前一日 CLV 的 t 约 +0.76；开盘成交占比的方向与预测相反（t +4.25）；之后时段才出现反弹（t −4.26） | 预先提出的开盘卖压预测未通过                                             |
| 基差修复                   | 弱收盘后的期现基差收敛主要发生在信号收盘至进场开盘之间，t 约 −8.8；现货在隔夜继续往下（收得越低，现货次日开盘越低，t 3.1），次日盘中再反弹（t −3.5） | 基差收敛发生在策略进场前，不能计作策略收益；可交易的部分更像现货自己的盘中修复 |
| 会员承接库存               | 收得越低，前 20 名会员汇总净多当天增加越多（2016 年起 t −6.4），次日再卖回（t +4.9）；控制 CLV 后，净多变化本身不预测收益 | 方向与"有人承接"相容；会员数据汇总多个客户，不能识别具体账户             |
| 融资与北向卖出             | 融资偿还、北向卖出与弱收盘同时出现；但"被迫卖得越多、之后反弹越强"的交互 t 约 −0.10            | 压力同时出现，不等于该压力导致了可交易补偿                               |
| 波动风险补偿               | QVIX × CLV 在 2016 年起 t −2.16、6 年同向，含 2015 年后 t −0.88；已实现波动的交互 2016 年起 t −1.91、含 2015 年 t −0.30；可交易持有段收益对波动分位 t 约 0.63 | 方向和 Nagel 的解释一致，但不稳，不足以据此加恐慌开关或动态加仓           |
| 反弹发生的时段             | 和其他日子比，弱收盘后的超额主要出现在次日 11:30—14:30（t −3.42），开盘到 10:00 不显著；但在持有段的绝对收益里，开盘第一分钟（+3.7 bp，t 5.1）和持有日收盘后的隔夜（+12.4 bp，t 4.2）贡献最大 | 不支持"开盘后立即承接"这一单一解释                                     |

因此，可以支持的结论是：研究期内有弱收盘后的收益关系，也观察到部分与流动性压力、承接相容的现象。不能支持的结论是：已经知道谁被迫卖出、哪一类账户承接，或融资/北向交易是收益来源。最关键的两条强度检验都没过：卖压越大，反弹并没有越大；风险越高，反弹也没有稳定地变大。机制不确定，也意味着没有稳健依据把这些外部变量变成新的仓位过滤条件。

我们也试过在收盘时把"会反弹的弱收盘"和"会继续跌的弱收盘"分开，包括趋势、放量缩量、波动状态、开盘位置、低位停留时间、下跌离散度、8 个日线量价特征，都没有找到在两段样本上都成立的区分方法。

### 四、冲高放大的证据

冲高的意思是：当天价格曾明显高于开盘，最后又收在低位。经济上的读法是，盘中有买方愿意出更高的价格，尾盘被压下来更像暂时的抛压，而不是新的坏消息，所以次日修复会更强。

- **在等权 CLV 策略上加冲高（×1.5）：** 年化多 3.34 个百分点，逐日差 t 3.69，7 年中 6 年为正。反过来，从当时的五部件完整策略里去掉冲高，年化少 3.66 个百分点（t 2.88）。两种拆法方向一致，是所有部件里最稳的一项。
- **登记的"冲高日加仓 vs 同敞口固定加仓"检验：** t 2.80，6/7 年，说明是挑日子而不只是多拿仓位。但去掉差值最大的 10 天后 t 降到 1.18，收益集中在少数大反弹日。早期 IF 上方向一致，t 1.29，而且主要来自熔断时点的差异。
- **形态检验：** 在弱收盘日里，控制 CLV 后，冲高幅度每增加 1 个标准差，下一段约多 72 bp（t 2.83）；早期 IF 上约 17 bp（t 1.93）。
- **从 1.5 倍到 2 倍：** 只比较了这一个变体，事先定的标准是年化更高、Sharpe 不降、回撤恶化不超过 2 个百分点。结果为 18.95%/1.49/−14.87%，对比 1.5 倍的 16.82%/1.44/−14.50%，按标准算通过。这只是一次样本内比较，不能说明 2 倍是最优。

### 五、从 CLV 单一信号到趋势与反转预算转移

单一 CLV 策略只在弱收盘后持有，平均实际敞口约 34%，持续上涨时会明显落后于满仓持有；增加底仓可以提高参与度，但也可能在熊市中承担更大方向风险。研究依次比较了常驻多头、均线、MACD、中期趋势投票，以及把趋势底仓与 CLV 预算结合的做法。

| 方案                                                |       年化净收益 |         Sharpe |           最大回撤 | 研究中得到的认识                                    |
| --------------------------------------------------- | ---------------: | -------------: | -----------------: | --------------------------------------------------- |
| 共同 CLV 冲高等权、无趋势底仓                       |           18.21% |           1.63 |            −9.13% | 收益集中于反转机会，平均实际敞口约 33.54%           |
| 常驻半仓多头 + CLV                                  |           13.99% |           1.22 |           −17.14% | 增加趋势参与，但熊市方向风险明显                    |
| EMA20 高于 EMA60 时持有底仓 + CLV                   |           13.25% |           1.35 |            −9.96% | 风险有所不同，整体收益没有改善                      |
| MACD 多空半仓 + CLV                                 |            8.18% |           1.02 |           −12.87% | MACD 柱会在上涨放缓时转弱，方向切换没有带来稳定增益 |
| 63/126/252 日趋势多数表决多空 + CLV                 |           10.72% |           1.09 |           −10.30% | 更慢的趋势判断未证明优于 CLV                        |
| 21/63/126 日纯多头分档、CLV 预算转移（历史版本） | 16.82% | 1.44 | −14.50% | 以预算转移代替空头对冲；提高参与度，但回撤恶化 |
| **当前 21/63/126 日纯多头分档、CLV 预算放大** | **18.95%** | **1.49** | **−14.87%** | 用户选择并冻结；历史样本内的风险收益取舍 |

这条迭代线不是"每加一个部件就改善"。几个关键的配对比较：

- 21/63/126 日纯多头分档（1.5 倍版）对比常驻半仓多头：年化多 2.45 个百分点，逐日差 t 1.75，7 年中 4 年更好，不显著。
- 63/126/252 日多数表决对比常驻多头：年化少 3.07 个百分点，t −1.24。
- 和无底仓的 CLV 冲高策略比，加上趋势底仓后平均敞口从约 34% 升到约 50%，但 Sharpe 从 1.63 降到 1.49，最大回撤从 −9.13% 加深到 −14.87%。

所以，在这个样本里，没有统计证据说明趋势择时比"一直拿半仓"更好。趋势底仓的经济依据来自国际期货的时间序列动量研究（Moskowitz、Ooi、Pedersen，2012），那里是几十个分散市场，不能直接推到三个高度相关的国内股指上。保留它是为了在上涨时多参与，是风险偏好的选择；预算转移使底仓和反转预算彼此竞争，趋势走弱时更多预算落到 CLV。当前版本是风险取舍，不是对所有历史候选的客观最优证明。

### 六、执行与成本

- **资金规模：** 1 亿元在 2015—2018 年会频繁撞上中金所当天的开仓限额（每天 10—50 手的阶段），所以回测改为 1,000 万元，基本不受限额影响。
- **成交口径：** 开盘价成交的各腿，按连续交易开始后 30 分钟内卖一/买一的均价成交，比"开盘价加一跳"更接近能做到的价格。弱收盘后早盘通常先涨，这个口径会把一部分早盘涨幅算成买入成本。
- **集合竞价买入：** 登记过一次检验，把买入改在集合竞价、按竞价后一档挂单估计冲击。每年约多 1.1 个百分点，t 1.63，7 年中 6 年更好，没有达到事先定的显著标准，默认口径没改。竞价阶段的真实冲击和成交率只能靠模拟盘确认。
- **成本量级：** 冻结版累计交易费用 255.68 万元，约占起始资金的 26%。成本在某些年份会吃掉大部分毛收益（见下面的 2021 年）。

## 冻结策略的逐年表现

下表为同一本连续权益账本的年度表现。2015 年从共同样本开始日计入，是部分年度；各年不重置本金。等权 BH 是同期间参照。

| 年份                 | 策略净收益 | 年内 Sharpe | 年内最大回撤 | 等权 BH 净收益 |         相对 BH |
| -------------------- | ---------: | ----------: | -----------: | -------------: | --------------: |
| 2015（4 月 16 日起） |     16.07% |        1.74 |      −4.49% |          1.23% | +14.84 个百分点 |
| 2016                 |     20.64% |        1.69 |      −6.50% |          2.51% | +18.13 个百分点 |
| 2017                 |     17.31% |        1.98 |      −4.83% |         12.92% |  +4.40 个百分点 |
| 2018                 |      8.66% |        0.62 |     −14.87% |       −14.90% | +23.55 个百分点 |
| 2019                 |     42.78% |        2.60 |      −7.41% |         18.97% | +23.80 个百分点 |
| 2020                 |     28.63% |        1.94 |      −5.76% |         17.46% | +11.17 个百分点 |
| 2021                 |    −1.33% |      −0.10 |      −8.24% |          2.04% | −3.37 个百分点 |

策略 7 年中有 6 年为正，但并非每年稳定盈利；2021 年落后于等权 BH。总体等权 BH 年化净收益约 5.34%、Sharpe 0.38、最大回撤 −36.10%。冻结策略相对 BH 的逐日超额 Newey–West t 值约 2.10，beta 约 0.41；这仍是同一研究样本内的统计，未对所有历史规则选择完全校正。全样本最大回撤出现在 2018 年，2018-02-12 触发过一次 10% 回撤停机。

### 2021 年：一个反例

2021 年是唯一的负收益年，也是落后 BH 最多的一年。拆开看有三个原因：

1. **毛收益很薄，成本把它吃掉了。** 当年毛盈亏约 +2.34%，交易费用约 3.67%（其中开盘滑点约 3.42%），净收益 −1.33%。弱收盘后的早盘上涨被 30 分钟拆单算成了买入成本。
2. **信号本身弱。** 2021 年弱收盘之后的下一段平均只有约 +6 bp，研究期整体约 +20 bp。这一年大小盘分化很大：现货沪深 300 全年约 −5%，上证 50 约 −10%，中证 500 约 +16%。三个品种的 CLV 方向经常不一致，等权平均后的信号不干净。
3. **政策冲击下的弱收盘不反弹。** 7 月净亏约 3.9%，主要是 7 月 26 日、27 日两天（约 −1.9%、−2.7%），对应教培行业政策引发的连续下跌。2 月下旬抱团股回落，22、24、25 日三天合计也亏了约 5.2%。这类下跌来自新信息，收在低位之后第二天往往继续跌，正好违背策略的前提。

### 适合什么样的市场

从逐年表现和上面的反例看，这个策略适合"跌下来之后经常有人接、波动不小但没有持续的信息冲击"的市场。2016、2018、2019 年超额最大：前两年是震荡和熊市，策略多数时间不满仓，又能在急跌后的反弹里赚钱；2019 年是急涨急跌交替。它不适合两类市场：一是平稳、单边上涨的大盘行情，比如 2017 年，平均敞口只有一半左右，天然跟不上满仓；二是政策或信息驱动的连续下跌和大小盘剧烈分化，比如 2021 年，弱收盘背后是真实的坏消息，反转的前提不成立。

## 经济逻辑到底有多硬

| 结论 | 证据强度 | 依据 |
| ---- | -------- | ---- |
| 2015—2021 年，弱收盘后下一段偏强 | 较强 | t 约 3，7/7 年；中间价口径不变；商品 2011—2021 同样成立，11/11 年 |
| 不是买卖价反弹造成的 | 较强 | 成交价与中间价 CLV 结果几乎一样 |
| 这个规律在股指上长期稳定 | 弱 | 早期 IF 和 2010—2015 现货都不成立 |
| 收益来自流动性压力和承接 | 部分 | 尾盘价差变宽、深度变薄、会员承接都和弱收盘同时出现；但卖压大小、风险高低都放大不了反弹 |
| 恐慌时补偿更高（风险补偿） | 不足 | 只有 QVIX 在 2016 年起的子样本里显著，含 2015 年不成立；已实现波动不显著 |
| 冲高放大有效 | 中等 | 两种拆法 t 2.9—3.7；但收益集中在少数日子，早期 IF 不显著 |
| 2 倍比 1.5 倍好 | 弱 | 只做了一次样本内比较 |
| 趋势底仓改善风险收益 | 不支持 | 相对常驻半仓不显著；相对无底仓，Sharpe 下降、回撤加深 |

如果要一句话回答"硬不硬"：作为一个统计现象，它在研究期里是硬的，而且跨了股指和商品两个市场；作为一个经济解释，它只是"与流动性压力相容"，还没有被证实；作为一个能长期赚钱的规律，它在股指上有过一段消失的时期，这一点最需要样本外来回答。

## 结论与边界

- **研究结论：** 研报中的日内时间因子没有证明在 CLV 之外提供稳定增量；CLV 的弱收盘信号在 2015—2021 共同样本中与下一段收益显著相关，冲高能进一步区分反弹更强的日子。
- **经济解释：** 流动性压力与承接现象有部分支持，但因果链和付款账户没有识别；融资、北向、波动等变量没有形成可靠的额外过滤器。
- **策略决定：** 采用中期多头趋势底仓、弱收盘时启用剩余预算、冲高时仅放大 CLV 预算；不做空。冻结表示当前规则暂不改动，不代表已证明优于所有历史版本。
- **仍然存在的风险：** 年度表现不平滑、2021 年为负；平稳上涨时会落后满仓持有；目标 2 倍不等于实际仓位上限；回测成本与执行是估算，开盘冲击和集合竞价成交率没有实测。
- **选择偏差：** 当前规则是在同一段样本上反复比较、由人选出来的。曾对一组 11 个历史变体做过 PBO 检验，结果约 0.69，意思是样本内最好的方案到另一半样本里经常排到中位数以下。这里的 Sharpe 和 t 值都应该打折看。
- **证据边界：** 所有结果来自反复研究的 2015—2021 样本，三个股指高度相关，本质上是对一个市场择时。当前策略的 2022—2025 样本外尚未运行；其中 2022、2024 两年曾用已退役的旧规则跑过，那两年的行情已经被看过，对当前策略来说不算完全未见的数据。冻结策略不代表已验证可部署优势。
