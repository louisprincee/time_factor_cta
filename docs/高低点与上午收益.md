# 高低点出现位置与上午收益（2016–2021）

时钟是本交易日夜盘第一根到 09:16 的相对位置：0 为夜盘开头，1 为 09:16。收益是同一天 09:17 开盘到 11:30 收盘的多头收益。样本是当年品种池里有夜盘的品种。p 值是 Spearman 相关的双尾检验，标准误按交易日聚类，同一天的品种不算独立样本。相关为负表示极值越晚、多头收益越低；下杀侧的正相关表示低点越晚、上午越容易反弹。

三条关系：

- 上冲：`dev15 > 0`，高点时钟对多头收益。预期为负。
- 下杀：`dev15 < 0`，低点时钟对多头收益。预期为正。
- 对齐：上冲用高点时钟、下杀用低点时钟，收益改成反向收益（上冲做空、下杀做多）。预期为正。

复现：`python scripts/morning_clock_return.py`。明细在 `runs/morning/clock_return/`。

## 结论

主结果只要求早盘偏离超过 0.2%，**没有**要求偏离方向和夜盘同向。

在这个样本上：低点出现得越晚，09:17 到 11:30 越容易反弹，斜率 +13.1 bp（p = 0.006），Spearman +0.052（p = 0.011）。高点出现得越晚，多头收益的点估计是下降 1.3 bp，但 p = 0.80，不能说高点越晚越容易下跌。上冲超过 0.2% 之后，五个时钟档的平均收益都是负的，上午回吐主要来自“已经上冲”，而不是“高点出得更晚”。

把“偏离方向和夜盘一致”也加上之后，下杀侧的反弹不再显著：斜率 +9.9 bp（p = 0.36），Spearman −0.014（p = 0.58）。上冲侧 Spearman 约为 0（p = 0.97）。所以不能把主结论说成“偏离超过 0.2% 且与夜盘同向时，低点越晚越反弹、高点越晚越下跌”。

## 图

两张图都用 2016–2021 的每一个交易日，37 个当年品种池里的品种、37,901 个品种日。位置从该品种夜盘第一根到 09:16，按路径五等分；09:16 这根 K 线在 09:17 开仓前已经知道，所以包含在内。收益是当天 09:17 开盘到 11:30 收盘的做多收益。高点和低点分开看，不再按偏离幅度或夜盘方向切样本。

![五段位置与做多收益](../runs/morning/clock_return/plots/segments.png)

高点位置与做多收益的 Spearman 为 −0.044（p < 0.001），时钟从 0 挪到 1 的收益斜率是 −5.3 bp（p = 0.002）。低点位置的 Spearman 为 +0.038（p < 0.001），斜率 +5.0 bp（p = 0.003）。五段均值里，只有高点落在最晚一段时，该段平均做多收益的 95% 区间不含 0（−3.5 bp，区间 −6.2 到 −0.7）。低点各段的区间都含 0，正相关来自整体排序。

![分板块 Spearman](../runs/morning/clock_return/plots/sectors.png)

六个板块各自计算，同一天的品种仍按交易日聚类。高点和低点都显著的是农产品、有色、化工。化工最清楚：高点 Spearman −0.081（p < 0.001），时钟从 0 挪到 1 的做多收益 −14.0 bp（p < 0.001）；低点 Spearman +0.067（p < 0.001），斜率 +13.2 bp（p < 0.001）。农产品低点 Spearman +0.045（p < 0.001），斜率 +4.6 bp（p = 0.012）；高点 Spearman −0.033（p = 0.011）。有色高点 Spearman −0.054（p < 0.001），低点 +0.033（p = 0.039）。黑色、贵金属、能源的 p 都大于 0.05。明细在 `runs/morning/clock_return/by_sector.csv`。

## 全期结果

“时钟 0 到 1”是极值从夜盘开头挪到 09:16 时，收益变化多少个基点。“晚减早”是时钟 ≥ 2/3 的平均收益减去时钟 ≤ 1/3 的平均收益。

| 上冲 | 18,496 | −0.034 | 0.003 | −2.4 bp | 0.26 | −1.9 bp | 0.32 |

上冲的秩相关显著，但收益斜率不显著：相关存在，经济幅度大约每个时钟全长 2 个基点。
