# 当日分数且展期为正：怎么定下来的

商品研究期 2016–2021。2015 只做预热。这条规则没有用 2024–2025 来选。四条已在 2026-10-21 一起冻结；`--validation`、`--year`、`--oos` 打开 2022 及以后时先记台账再读。不读 2026。

## 因子

两份研报对价格时间的方向是一致的，写在 `src/tfcta/config.py` 的 `FACTOR_SIGNS` 里，不按收益翻号。

| 因子 | 事前方向 | 含义 |
|---|---|---|
| `ts_low` | +1 | 低点来得晚，看多 |
| `ts_high` | −1 | 高点来得晚，看空 |
| `dfp_top3` | +1 | 收盘低于持续期公允价，看多 |
| `ts_low_pm` | +1 | 下午低点来得晚，看多 |
| `ts_high_pm` | −1 | 下午高点来得晚，看空 |

成交量、成交额打到极值的时点，两份研报方向相反，不进这个分数。

持续期阈值用研究期缓存的 N=250、M=55，落在研报 50–60 的中间，不是另搜出来的。下面的截面筛选主规格是 50 分位，见 `config/research/time_factor_screen.json`。两套数字不要混成一次寻优。

## 截面筛选没有给出可交易的配对

115 格里过全部门槛的只有 1 格，是股指收盘的 `dfp_top3_fixed`。允许配对的是 0 格。

|---|---:|---:|---:|---:|---:|---|

## 为什么做成全市场分数

筛选不允许配对。同一组因子在个股和板块上的轮动，研究期扣成本之后不赚钱，信息留在池子平均上。旧的只做多全市场时钟把这个结论记在 `docs/全市场时钟做法与表现.md`，那条策略本身已经删了。

## 规则

收盘才知道的分数大于 0，并且该品种滞后一个交易日的主力对次主力年化展期收益严格大于 0，下一交易日第一根开盘做多。有夜盘时这一根是夜盘开盘，没有夜盘时是日盘开盘。展期收益是米筐 `get_roll_yield(type="main_sub")` 的 `annualized_yield`，`yield` =（主力结算价 − 次主力结算价）/ 次主力结算价，研究期抽 3,840 天用合约日线复算，误差 1e-17。为正表示近月高于远月。回撤 10% 清仓，停 10 个交易日。

四条的规格都在 `strategies/market_clock_carry/`：

| 策略 | 分仓 | 名义敞口上限 |
|---|---|---|
| 按池宽1倍 | 每个入选品种拿 1 倍 × 权益 / 当年池宽 | 1 倍 |
| 入选平分1倍 | 入选品种平分 1 倍权益；入选数一变，所有持仓按新的份数重新平分 | 1 倍 |
| 按池宽1.5倍 | 每个入选品种拿 1.5 倍 × 权益 / 当年池宽 | 1.5 倍 |
| 入选平分1.5倍 | 入选品种平分 1.5 倍权益；入选数一变，所有持仓重新平分 | 1.5 倍 |

入选数和品种自己的权重都不变时继续持有，不随权益调手数，只成交手数差额。2026-10-21 之前，入选平分只在品种自己的权重变化时按当天入选数下单，老仓位不随入选数调，敞口最高漂到 1.39 倍和 2.17 倍；那一版的数字记在两份 JSON 的 `prior_information` 里。

## 研究期账

费用是历史手续费加每边 1 跳，一本 1 亿元账户。结果在 `runs/strategies/<id>/commodity/research/`。beta 和 alpha 相对池内等权开盘到开盘收益（不扣成本，1 倍），年化 alpha 是逐日残差均值乘 242，t 是 Newey–West 滞后 10。最大回撤从 1 亿起算，不受熔断恢复时重置峰值的影响。

| 策略 | 累计 | 年化 | 净 Sharpe | 回撤 | beta | 年化 alpha | NW t | 年化成本 | 最大敞口 |
|---|---|---|---|---|---|---|---|---|---|
| 按池宽1倍 | 51.70% | 7.15% | 1.36 | −5.70% | 0.25 | 3.69% | 2.22 | 3.04% | 0.80 |
| 入选平分1倍 | 102.02% | 12.36% | 1.19 | −11.13% | 0.50 | 5.52% | 1.74 | 6.08% | 1.04 |
| 按池宽1.5倍 | 86.61% | 10.89% | 1.36 | −8.48% | 0.38 | 5.60% | 2.23 | 4.57% | 1.22 |
| 入选平分1.5倍 | 184.86% | 18.95% | 1.22 | −16.41% | 0.73 | 8.67% | 1.80 | 8.99% | 1.59 |

六年每年净收益都为正。入选平分 1 倍在 2017-06-01 熔断一次；入选平分 1.5 倍在 2016-05-10、2017-04-19、2021-11-08 熔断三次，最大保证金占用 31.8%。

## 信号层检验

`python -m research.market_clock_carry_factors`，登记在 `config/research/market_clock_carry_factors.json`，结果在 `runs/research/market_clock_carry_factors/`。目标是收盘 t 决策对应的下一段开盘到开盘收益，不扣成本。登记前已经在草稿里看过这些数，所以是把看过的检验固定下来，不是新的确认。

| 检验 | 结果 | 年份 | 过登记门槛 |
|---|---|---|---|
| 分数择时：分数为正日减其余日的池子下一段收益 | +12.7bp/天（+12.4 对 −0.3），NW t 3.22；连续分数斜率 t 2.66 | 6/6 年为正 | 是 |
| 展期截面：滞后展期对下一段收益的 Spearman IC | 0.022，NW t 3.20；展期正减非正 3.9bp/天，t 1.94 | 5/6 年为正，2021 年为负 | 是 |
| 叠加：分数为正日的展期收益差减其余日 | 8.4bp 对 −0.01bp，差 NW t 2.25 | — | 是 |

板块上展期收益差 5 个板块都为正（贵金属只有两个品种，天数不足），但没有一个单独显著。

同一账本换条件（1 倍）：

| 条件 | 按池宽 净Sharpe / beta / alpha / t | 入选平分 净Sharpe / beta / alpha / t |
|---|---|---|
| 分数>0 且展期>0（策略） | 1.36 / 0.25 / 3.7% / 2.22 | 1.19 / 0.50 / 5.5% / 1.74 |
| 只看展期>0 | 1.17 / 0.65 / 2.1% / 1.19 | 1.10 / 1.05 / 2.0% / 0.75 |
| 只看分数>0 | 0.98 / 0.44 / 2.2% / 0.96 | 同左 |
| 全池常驻 | 1.05 / 1.03 / 0.2% / 0.16 | 1.03 / 0.97 / −0.1% / −0.05 |
| 分数≤0 且展期>0 | −0.58 / 0.31 / −7.4% / −4.30 | −0.58 / 0.57 / −13.9% / −4.47 |

两条腿都有信息，叠在一起比各自单用好。同样是展期为正的品种，分数不为正的日子持有相对池子年化亏 7.4%（t −4.3）。

## 对偶空头：研究期没过

`python -m research.market_clock_carry_short`，登记在 `config/research/market_clock_carry_short.json`，结果在 `runs/research/market_clock_carry_short/`。规则和多头完全对偶：收盘分数严格小于 0，并且滞后一日的展期收益严格小于 0（远月高于近月），下一交易日第一根开盘做空。冻结的四条不动。

| 检验（不扣成本，下一段开盘到开盘） | 均值 | NW t | 预期 |
|---|---:|---:|---|
| 分数 < 0 日的池子下一段收益 | −0.3bp/天 | −0.10 | 负 |
| 分数 < 0 日，展期 < 0 品种减池子 | +0.8bp/天 | +0.55 | 负 |
| 对偶空头篮子的下一段收益 | +0.5bp/天 | +0.16 | 负 |

分数的信息是单边的：分数为正之后池子涨得多（+12.4bp），分数为负之后池子并不跌（−0.3bp）。展期为负的品种在这些日子也不比池子差。

| 账本（1 倍） | 按池宽 净Sharpe / 回撤 | 入选平分 净Sharpe / 回撤 |
|---|---|---|
| 冻结多头 | 1.36 / −5.7% | 1.19 / −11.1% |
| 只做对偶空头 | −0.52 / −15.3% | −0.91 / −41.5% |
| 多空一本账 | 0.71 / −9.9% | 0.35 / −18.2% |

两条登记门槛都没过：空头两本账 Sharpe 为负，多空账的 Sharpe 低于冻结多头、回撤更深。研究期池子最深的三段回撤里，空头只在 2020-01-08 到 2020-04-01（池子 −17.8%）明显赚钱（+10.6% / +16.4%），2021 年 10–12 月和 2017 年 2–6 月只有 +1% 到 +3%，其余时间每年亏 2%–8%。同三段里冻结多头按池宽是 −0.3%、−1.5%、−3.2%，入选平分是 −0.4%、−2.9%、−8.5%；入选平分在这三段的平均敞口 0.45–0.61，并没有减仓。研究期商品池年化漂移约 13%，没有一两年的持续熊市，这一点研究期回答不了。
