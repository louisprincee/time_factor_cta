## 1. 先讲结论

这个项目研究中国商品期货的日内时间维度因子：日内高低点发生的时点、价格在日内停留较久的位置，是否能预测下一交易日收益。当前保留两条冻结的商品策略：

1. **按池宽1倍**（`market_clock_pool`）：全市场时间因子分数转为多头开关，再用滞后一日展期收益筛品种。
2. **按池宽1倍加慢趋势空头**（`market_clock_slow_short`）：多头腿完全相同，在市场慢趋势向下时，增加满足自身趋势向下且展期收益为负的空头。


## 2. 研究动机与经济直觉

策略尝试把两类信息结合起来：

- **日内时间因子**：市场什么时候形成高点或低点、价格在哪些位置停留较久，可能反映日内买卖压力和价格发现过程。
- **展期收益（carry）**：主力与次主力之间的期限结构，可能反映持有期货的风险溢价及供需、库存状态。

基本假说是：时间因子先识别整体市场环境，carry 再区分哪些品种适合持有多头。慢趋势空头则是在市场长期偏弱时，叠加品种自身的负趋势与负 carry。以上是经济解释和研究假说，不是已经验证的因果机制；carry 也只是期限结构指标，不等于真实换月盈亏。

## 3. 因子怎么计算

当前市场分数由五个方向预先固定的因子组成。方向是研究先验，不按研究期表现翻号。

| 因子 | 方向 | 直观含义 |
|---|---:|---|
| `ts_low` | + | 日内低点越晚，偏多 |
| `ts_high` | − | 日内高点越晚，偏空 |
| `dfp_top3` | + | 收盘低于日内停留较久价格的均值，偏多 |
| `ts_low_pm` | + | 下午低点越晚，偏多 |
| `ts_high_pm` | − | 下午高点越晚，偏空 |

### 持续期与公允价格偏离

持续期（duration）衡量分钟价格距离上一次显著价格变化已经过了多久：

1. 对每个品种，用**过去 250 个交易日、不含当天**的分钟绝对价格变化，计算第 55 百分位阈值。
2. 在当天逐分钟计算持续期；当天持续期最长的三个价格点的均值，构成 `dfp_top3` 的日内“公允价”代理。
3. 用该均值减收盘价，再除以原始收盘价，得到公允价偏离。正方向代表收盘低于这一代理价格时偏多。

N=250、M=55 是报告参数范围中的中间取值，不是从最终策略收益网格中挑出的最优点。因子实现主要在 [`src/tfcta/factors.py`](../src/tfcta/factors.py)，因子方向与参数定义在 [`src/tfcta/config.py`](../src/tfcta/config.py)。

### 时间戳与市场分数

高低点时戳按当日分钟位置归一化到 0–1；下午高低点只在下午交易时段内归一化。每个品种、每个因子分别使用该品种过去 250 个有效日值做滚动 z-score（至少 125 个观测，不含当天），并截断到 ±3。

先对每个品种当天至少 3 个可用因子的 z-score 求均值，再对当年有效品种池求均值，形成全市场分数；当天至少需要 10 个有效品种。商品时间坐标按整个交易日归一化，包含夜盘；夜盘 bar 按交易日归属规则归入下一交易日。

## 4. 两条策略的完整规则

### 4.1 按池宽1倍：市场择时 + 正 carry 多头

在交易日收盘时，若全市场分数大于零，且某品种**滞后一交易日**的主力对次主力年化展期收益严格大于零，该品种目标权重为 +1；否则为 0。

展期收益来自 RiceQuant `get_roll_yield(type="main_sub")`。原始 `yield` 定义为：

\[
\frac{\text{主力结算价}-\text{次主力结算价}}{\text{次主力结算价}}
\]

正值表示近月价格高于远月。项目曾在 3,840 个研究日上用合约日线复算，误差约 \(10^{-17}\)。池内任一品种某年 carry 缺失超过 5% 会报错，不会静默跳过。

**仓位预算：** 每个入选品种约分配“账户权益 / 当年池宽”的名义金额，所有入选品种加总的敞口不会因为入选数量变少而自动放大。

### 4.2 按池宽1倍加慢趋势空头

多头规则与上一策略完全相同。额外空头只在市场慢趋势小于零时启用：

- **市场趋势**：池内等权收盘到收盘日收益，分别累计 60、120、250 个交易日后取符号，再对三个符号取平均；结果小于零为熊市。任一窗口历史不足时没有趋势判断，因此不判为熊市。
- **品种趋势**：该品种 60、120、250 日收益符号的平均。
- 熊市日，若品种趋势小于零且滞后一日年化展期收益小于零，则目标权重为 −1。

负 carry 表示远月高于近月，在策略假说里可能是趋势与期限结构共同偏弱的筛选条件。

两条腿使用相同的池宽预算；多头要求 carry > 0，空头要求 carry < 0，所以一个品种同一天不会同时进入两条腿。

## 5. 执行、成本与风控

- 收盘信号在下一交易日第一根可交易开盘执行：有夜盘时为夜盘开盘，否则为日盘开盘。
- 目标权重不变就继续持有；只交易目标手数与当前手数之差，不因价格或权益变化自动再平衡。
- 回测采用整数手数、初始权益 1 亿元；保证金按名义金额 20% 估计。
- 历史手续费按金额费率 ×1.01，按手费率 +0.01 元；滑点按前一年估算的 tick，每边 1 跳。
- 峰值回撤达到 10% 时清仓并暂停 10 个交易日。恢复时风控峰值重置；报告最大回撤仍从初始资金累计计算。
- 换月按旧主力前一日收盘和新主力当日开盘收取手续费、滑点代理，不结转真实合约结算盈亏。

因此这些数字是带成本的研究账本估计，不是交易所级成交或保证金模拟。规则规格分别在 [`market_clock_pool.json`](../strategies/market_clock_carry/market_clock_pool.json) 和 [`market_clock_slow_short.json`](../strategies/market_clock_slow_short/market_clock_slow_short.json)，账本逻辑见 [`backtest/engine.py`](../backtest/engine.py)。

## 6. 研究结果与应如何解释

### 因子筛选

商品截面筛查中，`ts_low`、`dfp_top3` 的原始截面统计相对突出，但在控制后未通过完整门槛。115 个预先登记的格子里只有 1 格通过全部标准，获准配对的格子为 0。因此没有把这些因子做成商品个股截面多空，而选择检验市场级分数。

### 2016–2021 商品研究期账本

口径为 1 亿元、历史手续费加每边 1 跳滑点。

| 策略 | 年化净收益 | 净 Sharpe | 最大回撤 | 相对池子 beta | 年化 alpha | alpha NW t |
|---|---:|---:|---:|---:|---:|---:|
| 按池宽1倍 | 7.15% | 1.36 | −5.70% | 0.25 | 3.69% | 2.22 |
| 按池宽1倍加慢趋势空头 | 7.76% | 1.37 | −5.69% | 0.16 | 5.47% | 2.48 |

慢趋势空头在 294 个交易日持仓。研究期被判作熊市的日子里，池子年化收益反而约 +11.6%；这段样本因此没有充分检验到持续单边下跌环境下的保护效果。

### 信号层检验

已登记的信号层结果包括：分数为正日相对其余日的下一段池子收益差约 +12.7 bp/日，Newey–West \(t=3.22\)；carry 截面 IC 约 0.022，\(t=3.20\)；两者叠加差异的 \(t=2.25\)。但这些结果在正式登记前已在草稿中看过，不能当作独立确认。

按 100 次试验调整后的 Deflated Sharpe 两条策略都约为 0.06；基于 7 条账本序列的 CSCV 过拟合概率约为 0.53。应把研究期表现理解为继续检验的理由，而不是部署证据。完整研究说明见 [`docs/当日分数且展期为正.md`](./当日分数且展期为正.md)。

| 目录 | 职责 |
|---|---|
| [`src/tfcta/`](../src/tfcta/) | 路径与样本守卫、数据读取、因子计算、成本、分片与缓存准备 |
| [`strategies/`](../strategies/) | 当前两本策略的实现、JSON 规格和策略目录 |

| [`tests/`](../tests/) | 合成数据测试，覆盖因子、策略、成本、数据边界和账本 |

推荐讲解顺序：先讲因子动机和时间/价格停留定义，再讲市场分数与 carry 的分工，然后讲两本策略的规则和账本执行，最后展示研究期结果及其统计局限。

仓库根目录运行：

```bash
python -m backtest.engine --research
python -m backtest.engine 按池宽1倍 --research
python -m research.market_clock_carry_factors
python -m pytest
```

研究期为 2016–2021，2015 只用于预热。2022 年及以后受冻结、评估台账和数据读取守卫控制；不要为了复现或调参绕过这些限制。2026-10-22 按用户决定清空了商品 OOS 台账（`data/commodity/oos/ledger.jsonl`）和 2022 年及以后的结果文件。清空前，2022–2024 已经为当时的策略打开过，2025 没有打开记录。空台账不让任何年份变干净：2022–2024 重跑只算复现。策略 JSON 中的参数、冻结日期与代码实现会互相核对。
