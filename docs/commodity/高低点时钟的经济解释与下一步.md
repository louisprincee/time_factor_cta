# 高低点时钟：经济解释、个例与下一步（2016–2021）

本文合并了早期偏离检验报告，统一记录实验口径、结果解释和下一步：

- 夜盘以来的高低点出现早晚，为什么会和当天上午的收益有关？
- 这是不是巧合？
- 为什么有几年方向是反的？

本文最后给出下一步的具体做法。

所有数字只用 2016–2021 研究期。2022 是一次性验证集，2023 年以后不看。复现：

```bash
python scripts/commodity/morning_clock_return.py     # 相关、分档、分板块、截面 IC，输出 runs/commodity/morning/clock_return/
python scripts/commodity/morning_clock_cases.py      # 平均路径、个例、分解、状态分组，输出 runs/commodity/morning/clock_cases/
```

几个记号：

- 时钟：从本交易日夜盘第一根 K 线到 09:16 的相对位置，0 是夜盘开头，1 是 09:16。
- 低减高：低点时钟减高点时钟，取值在 −1 到 1 之间。
  - 接近 +1：夜盘一开始就是高点，09:16 附近是低点。也就是一路下杀到 09:16，下文简称"下杀"。
  - 接近 −1：一路冲高到 09:16，下文简称"冲高"。
- 收益：09:17 开盘到 11:30 收盘的多头收益，未扣成本。
- 按方向收益：下杀日做多、冲高日做空的收益。为正说明上午反转，即下文的"正例"。

### 与早期偏离检验的口径区别

早期报告考察的是早盘偏离 `|dev15| > 0.2%` 后，高点或低点时钟与上午收益的关系；本文主结果考察全部有效品种日的"低减高"，并在案例分析中额外使用 `|低减高| ≥ 0.6`。两者筛选条件和因子定义不同，不能把系数直接拼在一起，也不构成相互矛盾。

早期偏离样本的关键结果如下（2016–2021，09:17→11:30，未扣成本）：

| 关系 | 笔数 | Spearman | 时钟 0→1 收益 | p |
|---|---:|---:|---:|---:|
| 上冲：高点时钟→多头收益 | 4,524 | −0.020 | −1.3 bp | 0.80 |
| 下杀：低点时钟→多头收益 | 4,359 | +0.052 | +13.1 bp | 0.006 |
| 对齐：反向收益 | 8,883 | +0.035 | +7.1 bp | 0.042 |

该样本支持"下杀侧低点越晚，上午反弹越强"，但不支持上冲侧的单独时钟效应；再要求偏离方向与夜盘同向后，三种关系都不显著。因此主结论不应改写成"夜盘同向的大幅偏离必然反转"。细分结果仍见 `runs/commodity/morning/clock_return/`。

## 结论

1. 关系存在，但很弱。全样本 Spearman 为 +0.050，逐日截面 IC 为 +0.023（NW t 3.2）。几种稳健性检验都显著：
   - 循环平移置换 p = 0.0025；
   - 按天和按品种双向聚类 p < 0.001；
   - 37 个品种里 30 个为正。

   |低减高| ≥ 0.6 时，按方向收益约 +3bp，正例占比约 53%，低于单边成本，不能直接交易。
2. 这个因子测的主要是"09:16 附近是否刚打出新极值"，而不是"夜盘消化信息的快慢"。
   - 夜盘收益本身没有预测力。
   - 有预测力的是开盘后 16 分钟的走势，以及极值的时间位置。
   - 控制住各段收益和区间位置以后，时钟仍然显著。
3. 反转几乎全部来自 09:16 仍在顺着极值方向走的日子：+5.3bp，六年全为正。09:16 已经回头的日子只有 +0.2bp。
4. 年度差异是真的，不是围绕常数的随机波动：Cochran Q = 33.0，p < 1e-5。固定 19 个品种的面板也得到同样的年度形态，所以不是品种进出池造成的。
   - 2016 年四个季度全为负；
   - 2021 年只有四季度为负（−0.046）；
   - 2018Q4 和 2020Q1 也为负。

   负值集中在黑色和能源板块，以及大事件期间。
5. 可以提出、但还没有证实的解释：
   - 开盘时刻的流动性冲击（换班、外盘补跳空、止损和强平集中）会回吐；
   - 政策或宏观驱动的单边行情里，开盘打出的极值是信息，会延续；
   - 两者的比例决定这一年的方向。

   我试过的简单事前状态（过去 20 天开盘移动幅度、共振度）只在全期分档里有区分度，到年内就不稳定，还不能用。

## 2. 这个因子在商品上到底测的是什么

### 2.1 极值的位置分布

极值大多出在窗口两端（`segments.png` 里两端的样本最多），这是随机游走极值的反正弦分布。路径一直往一个方向走，高低点就必然落在两头。所以"低减高 ≈ +1"在机械上等于"从夜盘开始一路跌到 09:16"。因此需要先问：时钟是不是只是价格位置或涨跌幅的另一种写法？

### 2.2 分解

每天先做截面排名，再做回归，标准误按交易日聚类（`decompose.csv`）。变量相关：

| | 低减高 | 09:16 区间位置 | 昨收→09:16 | 夜盘收益 | 夜盘收盘→09:16 |
|---|---:|---:|---:|---:|---:|
| 低减高 | 1 | −0.72 | −0.73 | −0.62 | −0.36 |
| 09:16 区间位置 | | 1 | 0.75 | 0.44 | 0.68 |

回归系数，括号里是聚类 t：

| 模型 | 低减高 | 区间位置 | 昨收→09:16 | 夜盘收益 | 夜盘收盘→09:16 |
|---|---:|---:|---:|---:|---:|
| 单独 | +0.027 (4.15) | −0.022 (−3.10) | −0.007 (−0.98) | | |
| 夜盘 + 前 16 分钟 | | | | −0.001 (−0.17) | −0.034 (−4.40) |
| 低减高 + 区间位置 | +0.023 (2.94) | −0.008 (−0.92) | | | |
| 低减高 + 昨收→09:16 | +0.039 (4.94) | | +0.018 (1.96) | | |
| 全部 | +0.032 (3.94) | +0.012 (1.21) | | +0.011 (1.30) | −0.031 (−3.20) |

读法：

- 夜盘收益本身没有预测力（t −0.17），这一点和兴业报告"隔夜信息消化"的叙述不同。
- 开盘后 16 分钟的走势有反转（t −4.4），说明反转发生在日盘开盘这一段。
- 控制住区间位置后，区间位置不再显著，低减高仍然显著，所以时钟不只是"09:16 在区间的哪里"。
- 和"昨收→09:16"一起放进回归时，低减高的系数变大（t 4.94），涨跌幅本身反而转成弱延续（t +1.96）。也就是说，净涨跌幅这部分是延续的，可以看成信息；"极值刚在 09:16 附近打出来"这部分是反转的，可以看成冲击。
- 四个变量全放进去，低减高仍然有 t 3.9。

### 2.3 拆分：反转来自哪里

样本是 |低减高| ≥ 0.6 的日子，共 21,023 个品种日（`splits.csv`）。

| 拆分 | 组 | 品种日 | 正例占比 | 按方向收益 | 95% 区间 |
|---|---|---:|---:|---:|---|
| 09:16 前 15 分钟 | 仍在延伸（下杀日 dev15 < 0） | 12,059 | 55.6% | +5.3 bp | [3.0, 7.5] |
| | 已经回头 | 8,964 | 50.0% | +0.2 bp | [−2.4, 2.8] |
| 夜盘方向 | 和这段走势反向 | 3,816 | 54.3% | +5.2 bp | [2.1, 8.3] |
| | 同向 | 17,207 | 53.0% | +2.6 bp | [0.6, 4.6] |
| 夜盘幅度（品种内、年内三分） | 小 | 7,004 | 53.7% | +4.5 bp | [2.2, 6.9] |
| | 中 | 6,951 | 52.9% | +1.7 bp | [−0.7, 4.1] |
| | 大 | 7,068 | 53.0% | +3.0 bp | [0.1, 6.0] |

- "仍在延伸"六年都为正（+2.4 到 +9.1bp）。"已经回头"在 2016 年是 −5.6bp。
- "夜盘幅度小"六年都为正（+2.4 到 +7.9bp）。"夜盘幅度大"在 2016 年是 −5.0bp。
- 夜盘反向、极值打在开盘后的日子反转更强。这和"开盘后 16 分钟反转"一致。

这些拆分是看过结果之后才做的，只能当作下一步要事先声明的假设，不能当结论。

## 4. 经济解释

国债期货的叙述是"隔夜信息消化得早，市场更快形成共识，次日偏涨"。在商品上，第 2 节的结果不支持"夜盘消化"这条线：夜盘收益没有预测力，有效的是开盘后 16 分钟和"极值打在 09:16 附近"。更贴近数据的是下面几种机制。

### 4.1 开盘流动性冲击（反转的来源）

- 参与者在 09:00 换班。很多品种的夜盘以投机盘为主，产业客户和部分机构只在日盘下单。开盘前后订单集中，09:16 还在创新高或新低，说明这一侧的订单还没被吸收完。按 Grossman–Miller 的做市补偿逻辑，承接方要求价格让步，冲击过去后让步回吐，这是暂时性冲击。
- 外盘信息在 09:00 一次性兑现。农产品和化工的夜盘 23:00 收，之后 CBOT、原油还在交易，信息集中在开盘以跳空的形式补上。跳空本身是信息；开盘后再顺着跳空方向追出新极值，往往是过度反应。这和"夜盘收益无效、开盘 16 分钟反转"一致，也和"夜盘反向、极值打在开盘后的日子反转更强"一致。
- 止损和保证金强平集中触发。隔夜持仓的止损单和保证金不足的被动平仓集中在开盘执行，这类成交不带信息。
- 散户参与度。化工效果最强、黑色和能源最弱。化工品种散户占比高、单笔小，开盘过度反应更明显；黑色和能源的价格更多由政策和外盘主导。这一条我没有持仓结构数据，只是推测。

### 4.2 信息驱动的延续（反向年份的来源）

如果开盘打出的极值来自真实的供需或政策信息，它就不会回吐。商品上这类信息有几个特点：

- 国内政策的冲击幅度大、方向持续，例如去产能、环保限产、能耗双控、发改委保供稳价。
- 冲击常常是板块性的，一个板块一起动，截面上分不出谁是冲击、谁是信息。
- 期限结构和库存的变化会让趋势持续数周。

在这类时期，"极值出得晚"反而是趋势仍在加速的信号。

### 4.3 和之前结果的冲突

之前在 dev15 偏离（|dev15| > 0.2%）上做过"流动性还是信息"的代理变量检验。那一轮的脚本已删除，结论只留在研究记录里，结果和上面的简单预测相反：

- OI 下降的偏离反而回吐得更少；
- 板块共振的偏离反而回吐得更多。

所以 4.1 和 4.2 是可以写进报告的合理解释，但还没有任何一个独立的代理变量证实它。下一步的状态分组就是要检验这一点。

### 4.4 是不是巧合

- 整体关系不像巧合：置换检验、双向聚类、按品种和按板块的检验都显著，方向在 37 个品种里有 30 个一致。
- 年度差异也不是巧合：Q 检验 p < 1e-5，而且固定品种面板得到同样的结果。
- 但幅度很小。|低减高| ≥ 0.6 的按方向收益约 +3bp，正例占比约 53%。往返成本在低成本品种约 4bp，全池约 8–12bp。目前它只能当作条件信息，不能当独立信号。

## 5. 为什么有几年反向

## 6. 下一步

总原则：所有假设在 2016–2021 上事先写进配置，2022 只跑一次，2023 年以后不碰。每一项都同时看三个口径：逐日截面 IC、|低减高| ≥ 0.6 的按方向收益、按年和按板块的方向一致性。

### 6.1 按事前可观测的供需状态分组

目的：找到能区分"开盘极值会回吐"和"开盘极值会延续"的状态变量。

候选变量都是本地已有的数据，每个都要事先写明预期方向：

| 变量 | 数据 | 构造 | 预期 |
|---|---|---|---|
| 期限结构 | `data/commodity/external_rqdata/roll_yield/*_main_sub.pkl` | 主力和次主力的年化展期收益，品种内过去 250 天 z 分数 | 深度 back 且和走势同向时延续；接近平水时反转 |
| 库存变化 | `data/commodity/external_rqdata/warehouse/*.pkl` | 仓单 20 日变化率，品种内 z 分数 | 去库加上冲、累库加下杀时延续 |
| 持仓变化 | `data/commodity/minute_shards/*/open_interest/` | 夜盘到 09:16 的 OI 变化 / 过去 20 天 OI 均值 | 增仓推动的极值延续，减仓推动的极值反转（之前结果相反，作为重测） |
| 夜盘幅度 | 已有 | 品种内、年内三分 \|ret_night\| | 小幅反转，大幅延续 |
| 09:16 是否仍在延伸 | 已有 dev15 | dev15 的符号和走势方向是否一致 | 仍在延伸时反转更强（本文已看到，需要重测） |
| 板块共振 | 已有 | 当天同板块其他品种的同向比例（只用 09:16 之前的数据） | 共振高时延续 |
| 中期趋势 | 日频因子缓存 | 过去 20 天收益和走势同向 | 同向时延续 |

做法：

1. 新建 `config/commodity/clock_state.json`，写下变量、构造方式、分档方式（品种内三分或 z 分数 ±0.5）、预期方向和判定标准，然后提交，再开始跑。
2. 新建 `scripts/commodity/morning_clock_state.py`，复用 `morning_clock_return.load_research`、`daily_ic`、`cluster_slope`，以及 `morning_clock_cases.label_cases`、`rank_regression`。每个变量输出三样东西：
   - 分档后的截面 IC 和按方向收益；
   - 交互回归：收益排名 ~ 低减高排名 + 状态排名 + 低减高×状态，按交易日聚类；
   - 分年、分板块的符号表。
3. 判定标准（写进配置）：
   - 交互项 |t| > 2.5（按候选数做 Bonferroni，约 7 个）；
   - 高低两档的差在 6 年里至少 5 年同号；
   - 至少 4 个板块同号。
4. 通过的变量写成一条规则（例如"只在状态 X 时用时钟反转"），在 2022 上跑一次，把结果记进 ledger。
5. 需要注意：
   - 各变量互相相关，例如夜盘幅度和共振度，最后要放进同一个回归看谁留下来；
   - 有效样本是状态段的个数，不是交易日数；
   - 期限结构和库存一个月才变几次，独立观测很少。

### 6.3 比较 2016–2017、2021 和 2018–2020 的市场特征

目的：把 5.3 节的叙述变成可以检验的变量，而不是事后挑出来的故事。

1. 做一张月度状态表，2016-01 到 2021-12，共 72 个月：
   - 价格行情：自建等权商品指数（全池主力连续日收益平均）的 20 日收益、20 日波动、单边度（|累计收益| / 收益绝对值之和）；
   - 截面：各板块的平均两两相关、板块间收益离散度；
   - 宏观：PPI 同比和环比、PMI（需要手动从统计局下载，存为 `data/commodity/research/macro_monthly.csv`）；
   - 交易所事件：提保证金、限仓、调整手续费、夜盘时段变化，需要人工整理成事件表（日期、品种、类型），来源是各交易所公告；
   - 微观结构：每天 09:00–09:16 成交量占全天比例的月均值，作为开盘集中度。
2. 把月度截面 IC 对这些变量回归，或按单变量分档。72 个月的检验力很低，这一步只用来筛方向，每个变量只看符号和 t，不做组合挑选。
3. 事件研究：以事先列好的事件日为 0，看前后 ±20 个交易日的截面 IC 均值。事件列表必须在看 IC 之前定下来。
4. 夜盘刻度的稳健性：2019 年大商所、郑商所夜盘从 150 根缩到 120 根，同一个时钟值对应的绝对时间变了。
   - 用分钟数版本的时钟重算，即极值距 09:16 的分钟数，再除以固定的 390 分钟；
   - 或者只在 RB/HC/RU/BU（120 根不变）、有色（240 根不变）、贵金属（330 根不变）上看年度形态。
5. 判定标准：如果"共振度"或"单边度"高的月份 IC 系统性更低，就回到 6.1，用日频版本做成事前状态；如果只有事件哑变量能解释，结论就是"反向年份由少数不可预期的冲击造成"，这个因子只能配合风控使用，比如事件期间停用。

### 建议的行动顺序

1. **先做可交易性检验。** 重算 15:00 退出和成本后结果；若低成本子样本也不能稳定覆盖成本，暂不开发独立策略。当前 `|低减高| ≥ 0.6` 的毛收益约 +3bp，低于全池往返成本约 8–12bp。
2. **再检验机制假设。** 在看结果前冻结少量状态变量、构造方法、预期方向和判定阈值；优先检验 OI、期限结构/库存、板块共振等事前可观测变量与时钟的交互，按候选数校正多重检验，并报告分年、分板块稳定性。图中的成交量只能用于提出问题，不能代替这一步。
3. **最后才验证策略规则。** 只把通过研究期标准的规则写入配置，2022 按既定流程一次性验证；规则冻结后再做严格样本外或模拟盘，不在验证结果上反复调参。

若成本后只有特定状态或品种成立，更合理的用途是作为已有策略的排序/仓位过滤条件，而不是单独反转做多做空。只有成本后收益、跨年稳定性和一次性样本外验证都过关，才进入策略化。

### 阶段性追加结果（2026-10-14）

按上述顺序已完成 15:00 退出、现有状态代理、路径变量和早盘量能代理的检验。所有状态交互仍使用预先声明的 `|t| > 2.5`、至少 5/6 年同号和至少 4 个板块同号标准：

| 检验 | 结果 | 判定 |
|---|---|---|
| 15:00 退出，全样本 | 低减高 pooled Spearman +0.039；时钟斜率 +4.1bp（p=0.006）；截面 IC +0.025（NW t=3.54） | 关系仍在，但分年仍有 2016、2021 反向，2019 接近零 |
| 15:00，全部强时钟样本成本后 | 21,735 个品种日，毛收益 +3.67bp，估算成本 8.74bp，净收益 −5.07bp | 全池不能交易 |
| 15:00，`est_cost < 4bp` | 2,166 个品种日，毛收益 +6.28bp，净收益 +3.42bp，净正收益占比 50.1% | 均值为正但跨年不稳；2018、2019 净收益分别 −9.38、−4.16bp，且未计额外滑点，不放行为策略 |
| 期限结构 / 仓单 / OI 状态 | 主交互 t 分别 −1.57、+0.25、+0.94 | 都未过线，不能区分回吐与延续 |
| 尾段冲击占比 / 路径效率 | 主交互 t 分别 +1.90、−0.86 | 都未过线 |
| 开盘异常量 / 单位异常量价格冲击 / 量峰时间 | 主交互 t 分别 −1.29、+1.49、+2.32；量峰时间方向还与预期相反 | 都未过线；联合回归也没有留下稳定增量 |

这轮结果不等于“时钟关系不存在”，而是现有低频供需变量、分钟总量和简单路径特征都不足以稳定解释状态差异。再扩展大量同类特征的预期价值有限；下一步应优先取得主动买卖方向、盘口深度/价差或逐笔成交等订单流信息。若暂时没有这些数据，研究结论应停留在“弱而不稳定的条件信息”，不要把案例形态解释成已证实的流动性冲击。
